# 叮咚夜班开始

以“森林夜班便利店”为世界观主题的原创竖屏动物轻塔防小游戏，使用 Cocos Creator 3.8.8 开发，目标平台为抖音及微信小游戏，商业模式为 IAA。微信构建与平台验收尚未完成，软著申请暂缓。

> 正式中文名称统一为「叮咚夜班开始」，名称本身不包含感叹号、空格或书名号，用于与抖音后台和软著简称对齐。“守护芽芽”为早期工程代号；历史测试与截图中的旧名不用于新申报材料。项目只借鉴塔防品类的基础机制，不使用《保卫萝卜》的名称、角色、美术、关卡或音频素材。

世界观、角色方向和美术基调见 [世界观文档](./docs/WORLD_BUILDING.md)。
轻量塔防循环、店员扩展、道具和首版范围见 [核心玩法设计](./docs/GAMEPLAY.md)。
成熟休闲塔防的玩法、UI、交互和逻辑拆解见 [塔防核心参考分析](./docs/TOWER_DEFENSE_REFERENCE.md)。
实装前的审查结论见 [2026-09-27全项目复盘](./docs/PROJECT_REVIEW_2026-09-27.md)，其中旧结构与未接入状态属于该次复盘基点。当前0.5.0沿用0.4.1选定的B庭院地图：地铁口通向便利店，配合成组石花池与圆团小树；保留简洁Q萌角色、怪物、核心UI及十关玩法。最新集成状态与尚待验收项目见 [项目状态](./docs/PROJECT_STATUS.md)。

## 环境

- 项目目录：`G:\DEMO001`
- Cocos Creator：`F:\cocos2d\Creator\3.8.8\CocosCreator.exe`
- 设计分辨率：750 × 1334，竖屏，固定宽度、动态高度
- 语言：TypeScript

## 打开项目

1. 启动 Cocos Dashboard。
2. 选择“导入项目”，目录指向 `G:\DEMO001`。
3. 使用 Cocos Creator 3.8.8 打开。
4. 打开 `assets/scenes/battle/scn_battle.scene`，点击预览，从首页选择已解锁关卡。

## GM 调试选关

- Creator 预览或调试构建中，战场左下角显示紫色 `GM` 按钮。
- 打开面板后可直接进入第 1～10 关；面板开启期间战斗自动冻结。
- GM 切关、通关与失败均与正式解锁及最高纪录隔离；点击“返回正式进度”回到正式首页。
- 抖音正式构建会通过 Cocos `DEBUG` 编译常量移除 GM 入口与面板，不属于正式玩家功能。

## 当前可玩实现（0.5.0）

0.5.0补齐首页、继续最高已解锁关、已解锁关卡重玩，以及暂停/结算返回首页。返回结束当前局，重新进关从开局开始；修复存储异常、最高关卡回退及非法ID。保留名称、UUID、存档键、战斗数值和广告规则。基础优先级见[开发计划](./docs/FOUNDATION_PLAN.md)，微信待办见[发布准备](./docs/WECHAT_RELEASE.md)。

- 10 个连续关卡均使用独立路线和50像素逻辑网格；每关22个建造单元、12个开局空位、10个可清除障碍物。格位组成低对比地台，替代逐格椭圆底座；首尾地标及边缘格位已向屏内规划。第1～9关4波，第10关5波。
- 出怪前显示下一波与数字倒计时；提示结束后才开始计时。当前初始、波间和复活等待不同，取整后可能从5或6开始。倒计时已加入全棋盘备用位置搜索，避让建造、升级和障碍菜单，具体规则与验收见测试记录。
- 豆包（快速单体）、棉棉（减速控制）、布丁（范围驱赶）三名店员。
- 普通纸袋怪、高速红汽水罐、重型快递纸箱怪三种敌人。
- 先点空塔位再从塔位旁选择店员；点已建店员显示范围、升级与部分退款出售，点障碍物可指定清理并在清除后释放建造位；另有三个一键道具、正式的 1/2/3 倍速、暂停和胜负结算。
- 失败后可免费重开，也可每关主动选择一次“看广告继续营业”。广告实验流程按用户要求维持现状；当前占位广告配置和浏览器模拟奖励不代表真实广告验收或可发布状态。
- 前 3 关已按“豆包基础输出—棉棉克制疾行—布丁处理密集敌群”调优经济与波次，并加入建造、升级、攻击、击杀、漏怪、波次和结算反馈。
- 已接入 11 个原创合成短音效；音频异步加载失败时只跳过声音，不阻断战斗。
- 三名店员、木箱/购物篮/盆栽、三类怪物及三个道具已有精灵，建造菜单复用店员缩略图；地标为地铁口和迷你便利店，环境是不可清障的石花池/圆团树。`battle_art`共五张512×512图集，PNG合计591282字节，不等于发布包体或纹理内存。旧底座素材保留，战场使用数据驱动地台；历史候选仅在源资产中保留。
- UI包含奶油描边状态胶囊、心形耐久、橙色倍速、店员建造卡片及升级/出售/结算矢量皮肤；底部三个道具按钮为88×64逻辑像素、间隔8。文字与按钮状态由代码绘制，多帧动作、升级配饰与店长仍后置。
- 新增动态安全区与顶部平台胶囊避让，长屏上下延展；文字最低按24设计像素处理。极短安全区等比缩放并缩小塔位热区以避免交叠，该降级仍需真实设备体验。
- 通过`deviceScreen.windowSize`宽高比选择手机固定宽度或桌面完整等比显示；动态高度Mask裁去地图外图形。单次触摸移动超过24设计像素即锁定取消，滑回起点也不触发操作；第二触点、系统取消或切后台会取消当前点击。
- 表现粒子新增200个硬上限，超出时省略新增粒子，不改变伤害、奖励或战斗判定；这不等于低端机性能已经达标。
- 调试构建提供 GM 选关面板，可直接验证第 1～10 关；正式抖音构建不包含该入口。

0.4.1只改地图表现，路线、格位与数值不动；60局机器演练逐局结果与0.4.0一致，但这不等于人工胜率或真机性能验收。完整实屏、构建和遗留项以测试记录为准。

## 目录

```text
assets/
  scenes/battle/          # 战斗场景
  scripts/gameplay/       # 玩法代码
  scripts/services/       # 存档、平台等业务服务
  scripts/platform/       # 平台 API 适配，业务层不得直接调用 tt.*
  prefabs/                # 防御塔、敌人、投射物、特效与 UI 预制体
  art/gameplay/           # battle_art资源包：店员、公共件、敌人、场景四张图集
  art/ui/icons/           # 同一battle_art资源包中的道具图标图集
  resources/audio/        # 当前由 Cocos resources 运行时加载的音效
  data/                   # 关卡、数值、本地化和默认配置
  bundles/                # 通用、章节和音频分包
source_assets/            # PSD/AI/AEP/母带等生产源文件
docs/                     # 产品、架构、发布与计划文档
settings/                 # 需要纳入 Git 的 Cocos 项目设置
```

完整的分辨率、UI、目录、命名、图集、音频和性能规则见 [项目规范](./docs/PROJECT_STANDARDS.md)。
