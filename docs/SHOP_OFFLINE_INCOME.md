# 离线收益节奏修正 1.10.1

用户反馈本地账号上线直接获得大量金币，并确认：已有金币保留、离线最多2小时、满额收益以约1～2次当前经营改进为目标。

## 原因与处理

隔离实际ShopService复现，原有2万余额加上两小时1567金币，重复boot/show未再发钱。问题主要为原方案将离线按完整在线速度、全额利润推进。前版四架受控样本两小时平均7264、全设备八架42547，容易越过早期消费门槛。这些是隔离样本，不是读取玩家当前账号得到的数据。

保持正常前台营业和塔防规则。离线新增净收益取以下两项的较小值：实际离线经营利润的50%，以及当前待购预算按离线时长占两小时的比例折算。订单、库存、顾客和销量仍用同一经营算法推进，不凭空发固定补贴，不把旧余额计入奖励或预算，不回收历史金币。

满两小时预算优先取当前门店阶段允许、未购买的下一等级设备改进中最低两项费用之和，忽略余额限制；预算允许提前储备下一次扩店费，客流门槛仍在实际购买时校验，避免被动接待跨门槛导致拆段登录改变预算。若没有可改进设备，再参考已开放的商品研发、未雇佣店员和未收藏制服；只剩一项则取该项费用。全部完成后使用200金币预算。效率或陈列不足时可能低于预算，不保证任何指定两件物品都买得起。

收益短段按时长分摊，不足1金币的净收益作为offlineCreditRemainder在同一存档持久化。反复刷新、重复前台事件、整天离线都不能重复领取原时间段。前台连续停帧达到60秒（如系统睡眠、事件丢失）也遵循离线规则，避免无hide事件时补发全额在线收入。正常有帧更新的游戏期间继续全额经营。

原始ShopRule.xlsx先行增加offlineIncomeRatio=0.5、offlineBudgetPurchases=2、offlineCompleteBudget=200、onlineGapSeconds=60。Global/I18同步1.10.1和“离线收益”文案，仍由项目导表工具生成38张CSV与manifest。圆体补齐“益”字，957字形、缺字0；不新增绘图或图集资源。

经营存档版本3。v1沿用已有迁移后进入v2，v2只增加离线零头0并转为v3，保留余额、购买、库存、锁价订单和时间戳。正常在线收款不改价；离线利润折算是整个离线批次的新奖励政策，订单中原报价保留。修复离线零收益时残留成交飞币和“0金币”提示。
