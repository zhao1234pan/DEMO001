# UI资源与层级规范

同一替换槽位使用同尺寸透明画布。店员、进化、怪物、首领、道具与强化图标统一256×256；角色保留完整耳朵、武器和有意设计的独立弹丸，等比缩放，四周至少8像素透明留白。角色头像与全身图不混用裁切规则。原图不按均等网格猜测切割，ArtCut.xlsx明确源图、选区、完整连通块种子和源图SHA；换源图必须复核切图。

ArtFrame的width/height保留历史源图集区域；canvasWidth/canvasHeight才是独立PNG的画布尺寸。VisualSkin记录PNG尺寸、九宫边距和resizeMode。资源仅使用导入SpriteFrame，保留UUID、trimType=none、packable=true。PNG、meta、原始源图、XLSX、CSV和导出签名必须一并提交。

按钮、页签和条带按高度等比缩放九宫边角，仅拉伸横向中心。面板九宫横纵拉伸时保持边角比例，目标小于边距总和时统一缩小整张皮肤。图标、圆形按钮和装饰横幅使用contain等比适配；背景根据配置cover或stretch，不能用图标的尺寸适配规则。所有命中范围由父节点保留，图片缩放不改变点击逻辑。

同父节点从后到前：背景→遮罩→面板→装饰→图像→文本→状态标记→关闭/操作按钮。NewSkin和Artwork应在其父节点内容之前；不可把窗口标题横幅放在场景背景后。动态层保持地图→单位/弹道→HUD→操作菜单→弹窗的顺序。关闭、确认、刷新必须可见可点。

每次UI更新检查：全部PNG接触表及透明边界、同族画布、九宫预览、重复替换后比例、33个预制体层级、375×667/390×844/750×1334/1280×720截图与点击，覆盖首页、设置、选关、图鉴及详情、店员选择、三选一、战斗操作、暂停与结算。自动检查有效不代表视觉还原完成，必须人工查看截图。

程序只负责算法和Sprite缩放，不绘制UI资源。复杂物体边界需要人工选区复核；ArtCut种子是美术作者数据，九宫和布局参数仍按XLSX→CSV管理。原始PNG不变，作者工具清除与选定物体不相连的杂点，保留边缘抗锯齿；该技术处理不是重新生成美术。

## 2026-10-07 逐页效果图与单张资源补充

- 所有界面按效果图逐页核对，而非只复核用户圈出的控件。没有独立效果图的页面采用相同字色、描边、面板和按钮体系。
- 新增与重做资源采用单张PNG源文件，不再生图集后猜测分割。已有完整PNG逐张归档到ui_individual_20261007，来源与历史裁切保存在origins.json；历史源图集不参与当前导出。
- 客户端取消ArtAtlas与ArtFrame的旧图集坐标，只保留导入SpriteFrame路径与统一画布；历史XLSX移到design/archive，不读取它们。packable保持引擎标准设置，不据此宣称性能提升。
- UiLayout.xlsx统一管理33个预制体的节点位置、宽高、缩放、字号、行高、字体、字色、描边、对齐、初始可见与皮肤；导表生成CSV并回写Prefab。构建检查布局过期，禁止旧初始化工具覆盖布局。
- 同一按钮的文本框必须位于实际PNG可见内框，所有状态使用相同布局；标题与说明分行，不能压在下边框。中文使用无衬线字体，标题描边按参考单独配置，不能所有白字都套同一描边色。
- 固定地图缩略图禁止cover越过卡片。路线、塔位、店门按完整范围等比适配投影内框，预览不得覆盖关卡名称和边框。
- 店员选择头像用PNG模板裁切显示完整立绘，不剪掉源资源的耳朵/武器；勾选环在头像后，勾选标记在头像前。冒险和挑战共享两行四列的视觉结构，名单与人数仍由关卡配置决定。
- 加载条使用专用蓝色底槽、黄色斜纹和移动爪形端头，不能以通用按钮代替。真实进度、0/13/50/100%、美术失败重试和销毁中的异步回调均检查。

- 单张PNG制作与打包（2026-10-08）：新增和重做的UI、店员、怪物直接使用独立PNG；不默认生多资源大图再切，不再新增或启用自动图集。完整旧源图和图集配置可归档，运行资源使用独立SpriteFrame。布局、字体、皮肤参数通过UiLayout/VisualSkin原始XLSX导表；每个页面与参考图逐项对照，保留实际运行截图。
