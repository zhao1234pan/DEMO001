# 1.24.0 科技界面一致性与关卡配平

## 原因与配置设计

1.23.0总览每页6小卡加1宽卡，详情选中又切换到不同透明留白的胶囊皮肤；控件范围相近不代表可见PNG一致。本版所有总览卡为330×58，一页7行；分支节点统一330×58并使用同一tech_card皮肤，状态只变色。购买／翻页也保持各自同一PNG，禁用只灰度。图标仍等比放进相同槽，不拉伸轮廓。

原始Global／I18／UiLayout／Wave四XLSX先行，仍42CSV。文案、布局和波次倍率由原表管理；无新增难度字段、自动图集或可调硬编码。

## 科技收益与调节范围

按现表上限，最高店员直击持续输出比为1.12÷0.96＝1.1667，首领直击再×1.06＝1.2367；这是理想攻击间隔口径，并非全队实际DPS。另有射程4%、控制时长最多8%、建造省4%、升级省6%、开局15金币、清障收益与补给经验加成，因此关卡原有经济与输出窗口都会更宽。

按当前进度的固定曲线提高HP，不读取玩家科技数量动态补偿。以下均为相对1.23同一波、同一种怪的出生HP倍率增幅，按本关归一化波次平滑递进，保留旧曲线和波内衔接：

|关卡|普通怪与精英|首领|
|---|---|---|
|冒险1～3|前三波保持；其后由0%递进至12%|同普通曲线|
|冒险4～10|开波+6%→终波+24%|+10%→+30%|
|冒险11～20|+10%→+32%|+15%→+40%|
|冒险21～30|+12%→+38%|+18%→+45%|
|挑战10专题、各30波|+10%→+40%|+15%→+45%|

冒险首领实效由普通healthScale×bossHealthScale构成，因此bossHealthScale写入“目标首领增幅÷同波普通增幅”，避免叠加两次；挑战首领倍率独立，直接乘目标。挑战普通与精英的healthScale／eliteBaseHealthScale分别乘同一增幅，精英相对比例保持。终局保留原有首领与杂兵区别。

不改数量、出怪间隔、移速、奖励、开局金币、升级价格、怪物种类或补给次数。波内已入场怪物仍保留出生HP，不中途回血。未跑完整通关或长期养成测量，不宣称新的胜率或必需点满。
