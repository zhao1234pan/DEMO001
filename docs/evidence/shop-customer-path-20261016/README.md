# 顾客进出穿墙修正验收（2026-10-16）

## 问题与实现

用户截图[user-reported.png](user-reported.png)显示顾客出现在左上冰柜附近，头部被营业区顶部裁切。新版room背景隐藏旧Entrance，但ShopPoint仍使用旧墙面入口(-145,228)和转弯点(0,228)。

原始ShopPoint.xlsx五个坐标单元格改为下方中央入口／出口(0,-340)、转弯点(0,-260)。表现层依据实际营业区高度及扩店滚动范围整体平移入口，顾客沿中央地面进出；目标货架低于转弯点时不绕过目标再折返。空手离店的重开起点修正为货架前方，离店中改变视口也更新场外终点。没有改ShopSimulation、ShopService、收入规则、存档协议或玩家余额。
