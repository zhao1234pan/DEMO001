# 产品方案

## 定位

- 游戏名称：叮咚！夜班开始
- 早期工程代号：守护芽芽
- 世界观主题：森林夜班便利店
- 玩家代表：小浣熊夜班店长
- 首批店员：仓鼠豆包、垂耳兔棉棉、柯基布丁
- 类型：原创竖屏动物休闲轻塔防
- 平台：抖音小游戏
- 变现：IAA，以玩家主动触发的激励视频为主
- 单局目标：3～6 分钟，单手点击，失败后可快速重开
- 氛围：温暖治愈、轻松幽默，带少量夜间神秘感

完整世界观基线见 [WORLD_BUILDING.md](./WORLD_BUILDING.md)。

## 核心循环

部署动物店员 → 抵御夜间精怪 → 获得夜班收入 → 升级或调整岗位 → 营业到天亮 → 解锁后续内容。

## MVP 规则

- 基地初始 15 点生命，敌人抵达终点会造成 1～2 点伤害。
- 消灭敌人和完成波次可获得阳光。
- 防御塔最高 3 级，出售返还累计投入的 70%。
- 共 10 波；后续波次提高生命值并加入疾行和重甲敌人。

现有“防御塔、阳光、消灭敌人”等是可玩原型的技术占位术语，主题化时分别替换为动物店员、夜班收入和赶走/安抚精怪。

## IAA 设计原则

1. 广告必须由玩家明确点击触发，按钮清晰标注“看广告”。
2. 不把广告作为正常开局或关卡解锁的强制条件。
3. MVP 仅提供失败复活：每局最多一次，恢复 5 点生命。
4. 广告未填充、API 不支持或调用失败时提供不中断游戏的兜底。
5. 后续可测试结算奖励翻倍和临时道具，但每个节点只提供一个广告决策。
6. 插屏只考虑完整关卡结算后展示，并设置会话级频控；MVP 不接入。

## 美术与知识产权

动物店员、夜间精怪、便利店、地图和 UI 均采用原创设定。禁止直接使用或临摹其他游戏及现实便利店品牌的商标、包装、角色轮廓、关卡、美术、音效和文案。

## 首轮验证指标

- 首局完成率
- 首局失败波次分布
- 三类塔的建造占比和升级率
- 平均单局时长
- 激励广告请求、拉起、完整观看和奖励发放成功率
- 次日留存（有真实流量后）
