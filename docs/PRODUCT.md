# 产品方案

## 定位

- 工作名：守护芽芽
- 类型：原创竖屏轻塔防
- 平台：抖音小游戏
- 变现：IAA，以玩家主动触发的激励视频为主
- 单局目标：3～6 分钟，单手点击，失败后可快速重开

## 核心循环

建造防御塔 → 抵御波次 → 获得阳光 → 升级或调整塔阵 → 完成关卡 → 解锁后续内容。

## MVP 规则

- 基地初始 15 点生命，敌人抵达终点会造成 1～2 点伤害。
- 消灭敌人和完成波次可获得阳光。
- 防御塔最高 3 级，出售返还累计投入的 70%。
- 共 10 波；后续波次提高生命值并加入疾行和重甲敌人。

## IAA 设计原则

1. 广告必须由玩家明确点击触发，按钮清晰标注“看广告”。
2. 不把广告作为正常开局或关卡解锁的强制条件。
3. MVP 仅提供失败复活：每局最多一次，恢复 5 点生命。
4. 广告未填充、API 不支持或调用失败时提供不中断游戏的兜底。
5. 后续可测试结算奖励翻倍和临时道具，但每个节点只提供一个广告决策。
6. 插屏只考虑完整关卡结算后展示，并设置会话级频控；MVP 不接入。

## 美术与知识产权

植物精灵、捣蛋怪、地图和 UI 均采用原创设定。禁止直接使用或临摹其他游戏的商标、角色轮廓、关卡、美术、音效和文案。

## 首轮验证指标

- 首局完成率
- 首局失败波次分布
- 三类塔的建造占比和升级率
- 平均单局时长
- 激励广告请求、拉起、完整观看和奖励发放成功率
- 次日留存（有真实流量后）
