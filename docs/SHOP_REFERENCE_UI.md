## 排行榜范围与数据

此前入口只有“暂未开放”提示，没有全服／好友数据服务。本轮完成界面与只读本机进度，未接入平台排行榜，未生成假真实名次。开发时已说明并询问联网范围；在没有进一步平台指令时采用界面先行方案。

个人展示评分＝（冒险已解锁关数－1）×Global.rankingAdventureWeight＋已通关挑战专题数×Global.rankingChallengeWeight；两权重当前1000／5000，纯展示、不存储、不发金币。旧存档只拥有冒险解锁进度，不能据此声称已记录第20关首通或每关星级；个人栏因此显示解锁进度及真实挑战通关数。没有周榜重置、好友关系、全服上传或服务器名次。RankingEntry.xlsx中的8名店长全为演示资料，仅DEBUG可见。
