# 金币局外科技树（1.22.0）

## 已确认方向与参考

用户指定只新增局外科技养成，以便利店金币直接研究并长期生效，不扩大店员或补给候选池。参考《王国保卫战》全局升级树的分支与前置思路；Ironhide在[2026-09-11开发日志](https://www.ironhidegames.com/News/Details/522)说明回归原三部曲的全局塔升级系统。具体金币价格、效果及关卡门槛是本项目设计，不宣称为原作数值。

## 原始表先行

- 新增TechnologyBranch：id、key、order、staffKey、titleKey、iconKey；8店员分支＋后勤＋道具，共10分支。
- 新增TechnologyNode：id、key、branchKey、tier、prerequisite、cost、unlockLevel、nameKey、descriptionKey、effect、value；每分支5节点，共50项，按前置逐项研究。
- 新增TechnologyEffect：id、key、scope、attribute、operation、cap；属性绑定、加减／乘法和每分支累计上限由表管理。客户端只保留协议及应用算法。
- 修改Global版本、I18、UiPrefab、UiLayout，共7原表；导出42客户端CSV／manifest。新UI复用独立PNG及九宫，不生图集或运行时绘图。

## 首版效果与经济

- 店员分支：直击伤害、射程、攻速及专长（减速时长、爆炸范围、穿透长度、连锁衰减、灼烧时长、标记时长）；所有等级与进化形态适用。单分支直击伤害最多12%、射程4%、攻击间隔降低4%，专长最多8%。
- 后勤：建造最多便宜4%、升级／进化便宜6%、开局战斗金币增加15；出售按实际支付累计投入返还，免费券仍零投入。
- 道具：冻结总计增加1.4秒、金币道具增加16。保持原来的道具数量、首领漏怪与补给候选规则。
- 基础价格梯度180／600／1800／5200／14000，分支系数与进度门槛保存在节点原表。冒险通关逐步开放高阶节点；旧玩家可用已有金币研究。
- 冒险与挑战均生效；每局开始复制研究快照，局外购买／重置不修改已开始的战斗。科技页支持分页查看、节点说明、购买和二次点击确认的全额重置。

## 存档与入口

- 科技所有权与每项实际支付金额放入同一ShopState JSON，与金币一并保存；购买和退款不拆开写入，重复买／重复退款无效。
- 旧v3经营存档缺少technology字段时补空数组，保留余额、商品、员工、库存和已购商品研发。损坏的科技条目仅丢弃无效所有权，不清空经营进度或补发金币。
- 便利店原研究入口打开科技树；既有商品研发保留独立入口，不删除旧购买权益。本轮不新增经营成长或角色解锁系统。
