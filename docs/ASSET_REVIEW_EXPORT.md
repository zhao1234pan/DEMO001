导出清单记录每个文件的正式来源、SHA256和PNG尺寸；保留原UUID与透明画布。交接副本位于assets之外，避免Cocos重复导入。修改交接副本不会自动修改游戏；正式资源替换继续走原始XLSX→导表校验→CSV与原路径的PNG／meta。

原始资源、配置、来源及导出工具纳入Git；生成的美术副本和ZIP由`.gitignore`排除，避免每次版本重复提交二进制。新机器可按配置重新生成：

1. 使用已校验的新Web构建，在独立本地4346端口启动服务，避免操作用户正式存档。
2. 通过内置依赖加载工具定位Node与Playwright，配置NODE_PATH后运行`tools/art/capture-review-ui.cjs`。当前脚本保留1.20.0美术夹具与独立来源，后续版本按新UI状态更新夹具。
3. 运行`node tools/art/export-review.cjs`，汇总正式PNG、Prefab、字体、配置及已生成截图，生成`索引.html`和`导出清单.json`。
4. 将拆分PNG、防御塔、怪物、完整地图、场景与特效、UI效果图六目录打包为PNG素材.zip。

截图只使用隔离浏览器上下文；部分解锁、商店和胜负画面为明确设置的美术状态。完整界面和组件预览分目录，后者可能含静态占位文本；不能将其误称为真实游玩画面、真实胜利或所有设备视觉验收。
