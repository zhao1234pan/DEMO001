# 1.20.0 怪物扩充与经验补给

日期：2026-10-18。按用户最终要求：冒险初始金币保持原值，血量倍率乘1.5；怪物至少20种；挑战采用幸存者式经验进度条，每局最多20次补给，并联合配平关卡压力与补给收益。另按百鬼夜行的方式整理全部UI与资源。

## 怪物与冒险

- 现有6种普通怪和4种首领保留，新增14种普通怪，总计20普通怪＋4首领。8种新外观沿用同类属性，焦糖布丁、咖啡急客、草莓奶客、铁罐卫士、葡萄冻冻、饭盒壮壮6种调整了耐久／速度／奖励，形成较慢耐打或快步等不同倾向，没有声称增加14种全新技能机制。
- 全部24种都连接Enemy、ArtFrame、Collection、I18及真实WaveGroup，按关卡／挑战波序逐渐加入，保留每组数量与原出怪间隔。不能只在图鉴增加名字。新怪以同类混编，少量属性差异使挑战配方的平均基础血量略有增加，逐波静态值见[审计](evidence/monster-variety-wave-supply-20261018/balance-audit.json)。
- 原始Level.xlsx中20冒险关enemyHealthScale乘1.5，包含首领；initialCoins逐关与1.19.0一致。此前的逐波递进和冒险首领追加倍率保留。新怪个体属性另由Enemy表管理。
- 怪物标识类型改为来自配置的字符串，正式名单仍由Enemy表安装，不再在客户端维护第二份硬编码种类清单。

## 20次经验补给

- 开局选择1次，之后击退积攒经验触发19次升级，最多20次；不是固定每波弹窗。普通怪1经验、精英2、首领40。19次逐级门槛为80起每次加25，末次530，总计5795经验。未击退或大量漏怪会使进度变慢，不保证失败局也拿满20次。
- 顶栏下方蓝色PNG经验条显示当前补给次数和距下一次的经验；满格显示「补给即将送达」，等1.8真实秒后打开三选一，沿用0.25秒淡入误触保护。补给中停止游戏推进；暂停／广告不消耗送达等待。溢出经验留给下一次，达到20次后条满并明确提示上限。
- 同一波可以按经验获得多次补给，跨波也不会平白发卡。legacy choiceWaves保留为0的开局协议；经验门槛和三类经验奖励新增于ChallengeRule原表。ChallengePerk增加repeatable字段，原始XLSX先设计，再接schema、导表和客户端读取。

## 补给与难度一起配平

更多选择提供组合空间，同时收紧单张永久收益；不把补给数量翻倍等同于所有原科技直接翻倍堆叠。完整参数在ChallengePerk.xlsx／CSV，下面列关键变化。

| 效果 | 1.19.0 | 1.20.0 |
| --- | --- | --- |
| 豆包复制弹伤害比例 | 70% | 48% |
| 布丁延时礼花比例 | 90% | 50% |
| 咕咕距离奖励上限 | 35% | 20% |
| 邻柜／四类到岗加伤 | 25%／35% | 14%／18% |
| 持币加伤上限 | 20% | 12% |
| 备用金 | 200 | 90 |
| 免费建造／进化 | 3／2次 | 2／1次 |
| 额外普通击退收益 | 25% | 12%，小数累积保留 |
| 每波防漏护盾 | 2层 | 1层 |

其余电链、灼烧、标记、散射、利息、巨大化／迷你化、礼物／保龄球／糖果雨等参数同步配平，原有射程、站位和条件限制继续生效。修正S01成长文案为第11／21波。E06计算保留小数至最终战斗金币累积，避免12%收益在低奖励怪物上先向下取整为零。

新增3种可重复补给：40战斗金币、2秒冷风、1层临时门帘护盾。冷风在准备期留到下一波；门帘最多2层，准备期选择也留到下一波。重复卡不永久叠加伤害，解决后期科技已选／条件不满足时的候选不足；首领漏怪仍应致命，新增门禁拒绝过高的临时盾上限。

同样10张旧手动构筑、邻柜／到岗／持币封顶及成长2阶下，支援伤害倍率从2.7降到2.16；豆包复制轮平均系数从2.25降到1.7。这仅是单部分数值代理，不计新增10次选择、命中、范围和救场，不能据此声称实际DPS或通关率下降多少。没有再次整局模拟或完整30波试玩。
