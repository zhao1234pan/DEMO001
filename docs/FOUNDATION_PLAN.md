# 基础功能缺口与最小开发计划

版本：0.6.0。更新：2026-09-29。0.5.0已完成基础稳定性和玩家入口；本轮按用户请求扩展主界面、冒险大图选关、三页签图鉴及声音设置。依据当前代码和子模块检查记录，最终执行证据统一写入[测试记录](./TESTING.md)，不将待验证目标写成通过。

## 0.6.0最小闭环

1. 主界面：三个大入口与角落设置；冒险每页4张大图，共3页，正式首页初始化或战斗返回后默认定位最高解锁页。路线缩略图来自真实配置，未解锁关点击只弹条件。挑战明确暂未开放，不开新战斗。
2. 图鉴：怪物/BOSS/店员三页签；3怪物在正式首次出怪时收录，3店员随正式关进度开放，2个BOSS预留本版本始终锁定。旧档只从已完成关卡补录怪物；GM和MapReview不收录。解锁详情用真实参数与原创故事，锁定显示剪影问号。
3. 声音与设置：音乐、音效独立保存偏好；24秒原创BGM在首页和所有关卡复用一个循环源，11音效最多6个可停音源。首次触摸、加载失败、前后台、关闭开关与销毁有明确处理。设置仅保留音乐/音效/版本/返回；隐私/服务政策使用宿主机制与后台要求，不复制可选入口，不自编政策、数据说明或帮助反馈弹窗。
4. 平台：微信胶囊查询已有专属封装；抖音先检测侧边栏再展示无奖励入口。缺接口、抛错、失败、8秒无回调和晚到回调有兜底。未增加个人资料采集、账号或后端，不把接口替身测试当作平台审核通过。
5. 验证：截至当前已有图鉴13项、音频13项、平台24项、19项战斗机制以及60局固定策略逐局无差异证据。最终触控、菜单集成、三目标构建与浏览器结果由TESTING统一记录；两平台开发者工具、真机和人工听音仍待验收。

## 0.5.0最小闭环（历史实现，选关样式已由0.6.0替换）

1. 稳定性：继续使用既有数字存档键，不迁移、不清空旧存档。空白/无效值使用默认值，非有限写入忽略。最高解锁和既有最高关纪录通过`setMaximumInteger`将新值、会话值及旧档向下取整、夹到0～10后取最大值；旧档读失败时只留会话待落盘值，不执行写入，下次读取该键再尝试合并保存。倍速仍用普通`setNumber`，允许降低档位。没有后台定时重试；最高纪录在下次读取时尝试恢复。退出进程后不能保证恢复未写入的数据。
2. 首页：显示“叮咚夜班开始”、“继续闯关 · 第 N 关”、“已解锁 N / 10 关”和双列1～10关。N是最高已解锁关；新玩家只开放第1关，锁定项不可进入。
3. 进关与返回：选择已解锁关从开局开始。暂停页明确“结束本局并返回”，结算页提供“返回首页”；回首页后不继续波次、道具或本局对象。战斗内继续、失败重开及下一关保留既有规则。
4. 进度：正式通关只向前解锁，重玩低关不回退；首页不把“第10关已解锁”表示为“十关已通关”。GM不写正式进度，GM返回正式进度改回首页；MapReview保留独立评审行为。
5. 验证与记录：严格TypeScript、真实逻辑专项、既有战斗回归、Web Mobile和抖音目标构建、首页/战斗往返实屏检查。测试替身、浏览器点按、用户试玩与平台真机分别记录；未执行的检查明确保留。

## 验收要点

- 存储读失败、写失败、失败写入后旧值仍可读、空白/乱码、极大/负数/小数、NaN/Infinity均有明确结果，启动与结算不中断；还需覆盖“旧档读失败但写入可用”不覆盖旧档，以及恢复读取后合并更高旧档和会话新值。最高纪录正规化不回退，倍速仍可从3降到1。
- 新存档只可进第1关；冒险默认页包含最高已解锁关。三页前后边界正确，通关第1关后可进第2关，低关重玩不丢后续关卡；第10关无第11关入口。
- 首页不推进战斗，暂停/胜/负返回均清除本局状态；重进恢复本关初始零钱、耐久、道具与波次，倍速按既有偏好保留。
- 已解锁/锁定文案、绘制与命中一致；滑远再回、多触点、弹窗关闭不能意外进关或穿透建造。残留第二指代码已修，必须保留A下→B下→A上→A再下/上且B仍按的专项序列，不能据主指取消检查称所有路径通过。
- 图鉴未解锁不泄露名称和故事，BOSS本版始终锁定；新档、旧档补录、正式首次出怪、GM/评审隔离及存储失败恢复均有明确结果。
- 音乐与音效独立，偏好可开可关，首次触摸前无声音；菜单切换/重新进关不叠加BGM，关音效与后台停止在途声音，晚到加载不复活已停止/销毁声音。
- 平台缺接口、失败、超时应及时结束操作；微信胶囊实际避让与抖音侧边栏真实跳转必须在对应客户端验收；反馈由宿主菜单提供，不作为本游戏已实现功能。
- GM试关不提高正式解锁，回正式首页正确；MapReview可继续复现既有固定布阵。
- 375×667、750×1334、375×812和375×834视口下检查首页及返回按钮；记录实际点按范围，不用截图推断完整通关或手机体验。

## 本轮边界

不增加可玩挑战/BOSS战、新角色战斗能力、事件、关卡、星级、逐关评分、十关全通标记、局中存档、新手引导、局外养成或广告点位；战斗/道具数值、广告次数和发奖流程不改。图鉴只增加内容档案和本地发现标记。软著申请暂缓。微信保留正式App ID构建配置，新增实际使用的胶囊封装；名称结果、开发者工具、真实广告与真机仍待核验，不从休闲游戏类目通过推断完整发布通过。
