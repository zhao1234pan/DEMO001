# 基础功能缺口与最小开发计划

版本：0.5.0。更新：2026-09-29。依据为0.4.2工程、当前代码及既有测试记录；用户已选择先补“玩家入口：首页、已解锁关卡选择”。本文件记录优先级和验收要求，执行证据统一写入[测试记录](./TESTING.md)，不将待验证目标写成通过。

## 按优先级处理

| 优先级 | 真实缺口或风险 | 最小处理 | 本轮范围 |
| --- | --- | --- | --- |
| P1 | 存储异常条件下可能中断启动/结算；写失败可能使会话进度回退，旧档读失败时直接写入还可能覆盖未知的更高进度 | 捕获异常并保留会话值；最高纪录先读旧档取最大值，读失败暂不落盘，下次读取重试合并；倍速普通覆盖 | 已修；专项执行结果见TESTING |
| P1 | 损坏或非整数关卡进度可能与配置索引不一致 | 在关卡配置入口统一回退、取整与限界，运行ID取实际配置ID | 已修；专项执行结果见TESTING |
| P1 | 原流程启动即开战，没有正式首页、已解锁关卡重玩和返回入口 | 首页继续最高已解锁关、双列十关选择；暂停/结算返回；重玩不降进度 | 用户已选择，本轮实现 |
| P1 | 十关人工整局通关、后段搭配依赖与目标时长尚未验收 | 从第1/3/5/10关体验回路开始，逐关记录布阵、清障、失败波次与耗时，再决定是否调参 | 保留人工待办，不自动改数值 |
| P1（发布前） | 广告缺配置仍实际发奖/复活，SDK同步异常可能不复位；尚无真实广告验收 | 单独确认正式接入范围后修正结果与异常闭环，并做平台验证 | 广告本轮原样保留，不随稳定性修复扩改 |
| P1（发布前） | 微信本游戏未创建，名称/App ID、目标构建、平台适配及真机未验证；抖音也仍缺发布验收 | 核对后台事实后分别建立发布配置、平台分支与开发者工具/真机检查 | 本轮仅保留平台边界及明确待办 |
| P2 | 已复现残留第二指边界：A按下→B按下→A松开→A再次按下/松开，B始终未松，可能误触 | 后续需跟踪仍在屏幕上的触点，使多触取消覆盖残留手指；既有主指取消只覆盖首段序列 | 本轮未修，不能把多触验收目标写成全部通过 |
| P2 | 声音设置、暂停直接重开等基础操作尚未确定先后 | 当前可从暂停返回首页后重新进关；独立声音开关或更短重开路径另行确认 | 不抢在玩家入口之前新增 |
| P2 | 手机安全区/胶囊、密集遮挡、低端安卓帧率和内存缺真实证据 | 用相同版本做设备记录，覆盖长屏、短安全区、前后台与10分钟运行 | 保留真机待办，浏览器不能代替 |

## 0.5.0最小闭环

1. 稳定性：继续使用既有数字存档键，不迁移、不清空旧存档。空白/无效值使用默认值，非有限写入忽略。最高解锁和既有最高关纪录通过`setMaximumInteger`将新值、会话值及旧档向下取整、夹到0～10后取最大值；旧档读失败时只留会话待落盘值，不执行写入，下次读取该键再尝试合并保存。倍速仍用普通`setNumber`，允许降低档位。没有后台定时重试；最高纪录在下次读取时尝试恢复。退出进程后不能保证恢复未写入的数据。
2. 首页：显示“叮咚夜班开始”、“继续闯关 · 第 N 关”、“已解锁 N / 10 关”和双列1～10关。N是最高已解锁关；新玩家只开放第1关，锁定项不可进入。
3. 进关与返回：选择已解锁关从开局开始。暂停页明确“结束本局并返回”，结算页提供“返回首页”；回首页后不继续波次、道具或本局对象。战斗内继续、失败重开及下一关保留既有规则。
4. 进度：正式通关只向前解锁，重玩低关不回退；首页不把“第10关已解锁”表示为“十关已通关”。GM不写正式进度，GM返回正式进度改回首页；MapReview保留独立评审行为。
5. 验证与记录：严格TypeScript、真实逻辑专项、既有战斗回归、Web Mobile和抖音目标构建、首页/战斗往返实屏检查。测试替身、浏览器点按、用户试玩与平台真机分别记录；未执行的检查明确保留。

## 验收要点

- 存储读失败、写失败、失败写入后旧值仍可读、空白/乱码、极大/负数/小数、NaN/Infinity均有明确结果，启动与结算不中断；还需覆盖“旧档读失败但写入可用”不覆盖旧档，以及恢复读取后合并更高旧档和会话新值。最高纪录正规化不回退，倍速仍可从3降到1。
- 新存档只可进第1关；续玩进入最高已解锁关。通关第1关后可进第2关，重玩第1关不丢掉后续关卡；第10关无第11关入口。
- 首页不推进战斗，暂停/胜/负返回均清除本局状态；重进恢复本关初始零钱、耐久、道具与波次，倍速按既有偏好保留。
- 已解锁/锁定文案、绘制与命中一致；滑远再回、多触点、弹层关闭不应意外进关或穿透建造。这是验收目标：已复现的残留第二指序列仍未修复，不能据已有主指取消检查称所有多触路径通过。
- GM试关不提高正式解锁，回正式首页正确；MapReview可继续复现既有固定布阵。
- 375×667、750×1334、375×812和375×834视口下检查首页及返回按钮；记录实际点按范围，不用截图推断完整通关或手机体验。

## 本轮边界
