## 状态覆盖

- 冒险：已解锁/锁定卡、翻页、末页；挑战：开放/锁定专题、规则、开始/重玩、分页。
- 准备：八选四完整两行、短名单收紧、已选/未选、人数不足禁用；沿用既有实际交互回归。
- 补给：待选、刷新可用/用完/加载中、已持有列表；已持有列表不再显示“选择”。每次选择一次广告刷新、无结束本局按钮仍按原逻辑。
- 图鉴：店员/怪物与首领/商品滚动，基础一二级、进化、制服、未知详情；长详情遮罩随缩放反向扩展覆盖画布。
- 商店：营业内景、八货架、三商品位、雇佣/设备改进/商品研发/制服三行弹窗、九商品上架、已拥有/锁定/不足金币；保留当前模拟经营和交易。
- 排行榜：调试演示、好友筛选、正式未联网、个人真实成绩；科技：总览与五级详情、已购/未购、前置与余额约束。
- 战斗：HUD、首领、来客预告、建造、升级/出售、进化、障碍说明、引导、暂停、胜/败/重试、提示与GM。
- 加载：离线查看13%、50%、100%条槽/黄条/端头关系，并逐百分比检查端头边界。
