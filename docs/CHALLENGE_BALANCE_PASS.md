# 1.19.0 挑战模式单次数值调整

日期：2026-10-18。依据[1.18.0实际30波试玩](CHALLENGE_MANUAL_30.md)，用户要求「按照你的理解改一波数值，不需要改完测试」。本次只做一个配置版本，没有进行模拟、回归、试玩或Creator构建，4344预览仍为1.18.0。

## 调整内容

六个挑战专题同步调整，普通冒险不在此次范围内。

1. 第15～29波重新分配现有怪物的数量占比。以各专题第14波的配方平均基础血量为锚点，后续每波增加该锚点的2.5%，逐渐提高混合配方强度；优先沿用原波怪种偏好，避免23～24波突然变软、25波突然大幅变硬、27波又回落。冷链专题仍不使用厚血怪，仓库专题仍不使用普通怪。
2. 第15波开始叠加普通怪血量增幅，每波增加1.8个百分点，第24波达到18%，后续保持该增幅。原有逐波倍率和波内衔接算法继续生效。调整怪种配比也影响对应精英的基础血量、移动速度和击退奖励，不能把这次变化解释为只改了HP。
3. 第20波首领血量提高15%，第30波首领提高50%。夜班试营业终局钟表首领从31680变为47520；首领移动、漏怪伤害、队列位置保持。
4. 第30波普通怪的配方平均开波HP代理调至旧版约90%，精英基础血量也随配方变化降低；最终波内新怪血量追加增长从15%改为5%。该字段在启用跨波衔接时仅影响最后一波；前29波仍按下一波倍率衔接。目标是让终局主压力更集中于首领，杂兵仍能成片击退。

本轮保留30波、每波140游戏秒、每组数量与组序号、总出怪量、出怪间隔、首领位置和队列几何；没有用加流量替代强度配平。科技、升级价格、金币规则和补给节奏未修改；怪种配比改变后实际击退收入仍可能变化。真实时长与新难度没有复验。
