## 第二轮复盘纠正的细节

- 旧材料把“清场”写成快速清理地图障碍，实际代码针对精怪；地图障碍需要正常指定目标，由射程内店员攻击。新稿区分这两种操作，并补清障前后实屏。
- 挑战只隔离冒险最高开放进度，实际遭遇的精怪仍可记录图鉴；新稿按冻结源码与实际状态描述，不沿用旧稿“挑战不记录遭遇”的说法。
- 冻结挑战有21波，不能将后来版本的挑战规则倒推进V1.0.1。原始关卡、角色、地图与I18作为正文数值和文字来源。
- V1.0.1免费道具次数为0，正式广告位仍是占位值。新稿第15页如实说明三种道具效果及真实成功条件，展示实际不可用和未复活提示，没有伪造广告成功后的效果图。
- 终关按钮实际显示“再次挑战”，按实际画面核对正文用词；数字、按钮名和操作去向都与同版界面对应。
- 不再使用旧脚本直接切换胜负状态的截图。自然胜利图均为最终波次且耐久大于0，自然失败图耐久为0；可通过原图状态、操作日志和录屏追溯。
