# 独立便利店自动经营 Demo（1.8.0）

本轮按2026-10-11确认制作：首次开店一次性100金币，面包和牛奶自带，其余7件商品分别随冒险第1～7关首通解锁；已有冒险进度自动补齐。关闭或退后台最多累计2小时营业。

## 试玩

入口：http://127.0.0.1:4344/ 。首页点击“商店”。顾客自动进店、拿货、排队付款、离店；库存自动补齐，金币直接到账。可以先雇佣棉棉或改进收银/补货，再返回塔防观察经营继续运行。

- 店员：8位既有店员，沿用原解锁条件，单独用经营金币永久雇佣，不占战斗阵容。所有雇佣效果持续有效，最多显示4位自动轮换，没有排班、工资和疲劳。
- 改进：收银3级、补货3级、货架由2组扩至3/4组。未开放货架可点进改进页。
- 商品：图鉴与经营用同一真实首通条件。点击已有货架，再选已解锁商品上架；新商品进入候选，不擅自替换已有货架。
- 离线：自动到账，提示本次收入；重进商店、刷新页面不会重新发礼金或重复领取收入。
- 金币：与战斗金币和爱心分开，仅在经营内消费。没有装饰升级、手动收款、经营广告或战斗道具兑换。

## 配置与资源

6张新增原始表：ShopRule、ShopGoods、ShopStaff、ShopUpgrade、ShopCustomer、ShopPoint。既有Goods、Global、I18、UiPrefab、VisualSkin、UiLayout按范围追加/修改，原始XLSX、CSV、manifest、导表协议同次提交；总计34表、34预制体、1840布局节点。

固定内景为单张完整PNG，归入assets/art/ui/windows/shop；源图和内置图像工具提示词归档到source_assets/art/production/auto_shop_20261011。复用既有圆体、九宫按钮、货架、商品和角色独立PNG，没有新增图集或运行绘图。Demo来客暂时复用啾啾、咕咕、栗栗形象，不表示新增正式角色。

ShopSimulation负责独立时间与订单，ShopService管理全局唯一经营实例和存档，ShopView只投影状态。经营与金币保存在同一JSON中；保留旧局外金币迁移入口，GM重置同时清空经营。GM图鉴预览不解锁真实商品，美术评审不启动经营。

## 验证与边界

27项经营/存档/配置回归、31项配置回归、27项挑战、12项PNG资源、13项图鉴/布局，共110项；严格TypeScript及34表过期门禁通过。真实画面与构建诊断见docs/evidence/auto-shop-demo-1.8.0/README.md。

这是固定店面和现有9件商品的试玩，不包含挑战扩关、20关各一件新商品、美术装饰升级或皮肤商店。两小时离线使用设备本地时间，不引入服务器；时间倒退时不发收益。正式平台真机和长期经营平衡尚未验收。
