# 挑战怪群分流与构筑成长（1.14.0）

2026-10-17：移动与构筑实现保持，当前普通／精英血量已由[1.15.0数值复调](CHALLENGE_DIFFICULTY.md)接续；下文1.14.0参数和测试为历史，不作为新版难度结论。

用户确认保留放置店员塔防操作，优先解决怪物叠成一排和挑战缺乏割草感的问题。本轮完成怪群占位、连续出怪、专属成长和精英／首领压力；便利店金币新解锁交易不在本轮范围。试玩为同源4344的1.14.0，原经营与冒险进度继续使用。

## 怪群通行

- `CrowdFlow`沿原地图路线生成左右两列，普通怪按空闲列入场，首领使用中间道路。入口先检查占位，没有空间时等待，不把新对象硬塞到同一坐标。
- 身体使用轴对齐安全框，普通半尺寸15、首领24，框之间留3逻辑像素；`crowdRadius`这个字段名实际表示安全框半尺寸。精灵比例、脚底到身体中心的抬升量分别由Enemy原表管理，攻击、弹道和表现共用实际位置。
- 从前往后推进，按当前路段与投影比较前后；前方角色预留转弯后的空间，避免两列内外弯互相卡死。大步移动分段检查，返场／复活逐个重新找位置，放不下者在场外等待。
- 普通角色复用原独立PNG并等比缩小，精英使用金色地面环和血条识别；满血普通怪隐藏血条，受伤后显示。首领更大，血条保持可见。本轮没有新增图集或运行时绘制资源。
- 这套规则用于所有可玩的挑战会话，包括GM；静态地图评审不使用。冒险移动、原有Enemy字段以及20关的Level／Wave／WaveGroup内容保持。

## 连续阶段与压力

仍为15个阶段、10次补给选择，5／10／15有首领。每阶段175游戏秒，准备10真实秒，阶段之间无额外空档；3倍速自动策略约15分钟，不含思考、暂停、广告和低帧率影响。玩家首页继续写“共15波”，不写倍速耗时估计。

WaveGroup现在是各阶段的混合出怪模板：240～350名普通怪按种类交织，间隔0.65→0.42游戏秒；模板用完且阶段未到点时继续补普通怪，首领不重复补。首领排在首轮模板约15%处。到点停掉尚未出生的小怪，已入场怪物跨阶段继续前进，不等全清才开始下一阶段；不为未出生者结算击败或金币。第15阶段到点后停止出怪，最终还需清掉实际存活怪群。切阶段保留已发出的连爆、电球等效果。

从第3阶段起每8名一名精英，基础4倍血量，之后每阶段增加12%；速度1.35倍，奖励2倍，身体占位保持普通尺寸。普通怪每阶段额外增加2.5%移速。首领速度为基础90%，漏过伤害20，不能靠剩余耐久或2点护盾轻松放过。校验要求首领伤害覆盖初始耐久与配置护盾。

六路线仍分别调整血量。普通HP倍率从0.4开始，21／23／26平方增长到6、24到2.8、25到10，22立方增长到9。多数首领基于e9e4018倍率×1.6，22后期额外立方增长到该基线×6.4。初始战斗金币650，击败金币折算8.5%，小数在本局累积；不改便利店钱包，不新增局外战力。
