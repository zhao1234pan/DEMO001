## 改动清单

- 取消按整张图平均分格裁切。ArtCut原始表明确120项源图、完整物体种子、选区、源图SHA、边缘和透明留白；导出保留选定对象及其独立弹丸，清除相邻物件和杂点。修复齿轮夹带书页、书本与头像边缘截断、商品漏切、进化武器/弹丸跨格被切掉。
- 83项ArtFrame统一256×256透明画布；常用图标、商品和圆形按钮同样统一画布。等比放入并保留8像素外边界，原UUID保持。ArtFrame历史源图集width/height保留，新增canvasWidth/canvasHeight，避免把来源矩形误当运行PNG尺寸。
- VisualSkin新增resizeMode。按钮/页签/货架按高度等比九宫适配；图标与横幅contain；面板缩小时连同角部等比缩放，再延伸中心。修复按钮角部压扁、薄荷面板压缩、书页边角放大形成竖条，以及隐藏零尺寸节点出现非有限尺寸的风险。
- 整理33个预制体的背景、遮罩、面板、图像、文字与操作按钮顺序。修复挑战配队Banner处于不透明地图后、NewSkin可能盖住内容、按钮表面盖字；补齐图鉴遮罩，调整标题、关闭按钮和横幅留白，隐藏压住角色名的旧计数。
- 不改建造、升级/出售、进化、配队或选卡逻辑；空白点击关闭菜单继续有效。玩法数值CSV仅Global版本由1.7.0改为1.7.1，其余玩法表与基线一致。
- 规范见UI_RESOURCE_STANDARD.md，并更新项目及跨项目约定。新增检查覆盖同族画布、透明边界、PNG/meta实际尺寸、源图/选区/PNG签名、层级和适配模式；旧导出入口转入当前原始表流程，避免恢复旧图。
