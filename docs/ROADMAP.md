# 路线图

## M0：可玩原型（已完成）

- [x] Cocos Creator 3.8.8 工程
- [x] 竖屏单关卡与基础波次敌人
- [x] 三种占位塔、三种敌人、升级与胜负流程
- [x] 胜负、暂停、广告复活接口
- [x] TypeScript 严格检查、Web Mobile 与抖音小游戏构建验收
- [x] Creator Web 构建浏览器预览与核心点按验收

## M1：核心体验（当前）

- [x] 建立 10 个连续编号关卡和 3～5 个自动波次的数据配置。
- [x] 改为自动波次、固定塔位、选中后升级的轻量流程。
- [x] 实现豆包、棉棉、布丁及冰柜冷气、闭店清场、紧急零钱三个一键道具。
- [x] 实现免费重开、一次可选失败广告复活和道具广告补用接口。
- [x] 为前 10 关建立不同路线、有效塔位和基础递增难度曲线。
- [x] 将建造与升级改为跟随塔位的上下文操作，降低学习和误触成本。
- [x] 增加面向玩家的 1、2、3 倍正式战斗速度，并保存玩家选择。
- [x] 修复 750 × 1334 等比适配，并增加首波、波间和复活后的出怪倒计时。
- [ ] 将每关 4～6 个显眼塔位重做为 12～18 个弱化/隐藏建造单元，形成约 8～12 名店员的成型防线。
- [ ] 增加可指定攻击的障碍物、清障零钱和清除后释放建造空间。
- [ ] 增加部分退款出售，并将建造、升级、出售改为紧凑的上下文操作。
- [ ] 根据新棋盘密度重做原创战斗效果图，压缩角色、环境装饰和常驻 UI 占地。
- [ ] 完成第 2～10 关逐关人工通关，并调到目标时长和合理难度。
- [ ] 验证 1 种简单关卡事件，只有确实增加乐趣才保留。
- [x] 建立音效服务，并接入首批原创局内短音效。
- [ ] 建立对象池。
- [ ] 原创 UI、角色、地图和特效第一版。
- [ ] 建立难度曲线与基础埋点。
- 新手引导暂不进入当前计划，先用熟悉操作、倒计时和即时反馈验证轻量体验。

## M2：留存系统

- 按验证结果逐步扩充到 8～12 名店员，每关保持 3～4 名可用。
- 增加敌人组合和少量已验证的特殊事件。
- 离线/本地存档版本迁移。
- A/B 配置和远程参数预留。
- 星级、每日任务、装修、图鉴等局外系统不进入默认计划，只有核心玩法数据证明需要时再立项。

## M3：商业化与提审

- 接入真实激励视频广告位和完整埋点。
- 评估结算翻倍；按数据决定是否接入低频插屏。
- 抖音真机矩阵、包体、弱网、生命周期和合规测试。
- 准备图标、截图、录屏、隐私说明、适龄提示和资质材料。
