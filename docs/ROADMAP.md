# 路线图

## M0：可玩原型（当前）

- [x] Cocos Creator 3.8.8 工程
- [x] 竖屏单关卡与 10 波敌人
- [x] 三种塔、三种敌人、升级与出售
- [x] 胜负、暂停、广告复活接口
- [x] TypeScript 严格检查、Web Mobile 与抖音小游戏构建验收
- [ ] Creator 浏览器预览人工试玩验收

## M1：核心体验

- 完成 10 个 60～120 秒的连续编号关卡。
- 将原型改为自动波次、固定塔位和点击升级的轻量流程。
- 实现豆包、棉棉、布丁及冰柜冷气、闭店清场、紧急零钱三个一键道具。
- 验证 1～2 种简单关卡事件和一次失败广告救援。
- 关卡配置数据化、对象池、音效管理和新手引导。
- 原创 UI、角色、地图、特效和音频第一版。
- 建立难度曲线与基础埋点。

## M2：留存系统

- 按验证结果逐步扩充到 8～12 名店员，每关保持 3～4 名可用。
- 增加敌人组合和少量已验证的特殊事件。
- 离线/本地存档版本迁移。
- A/B 配置和远程参数预留。
- 星级、每日任务、装修、图鉴等局外系统不进入默认计划，只有核心玩法数据证明需要时再立项。

## M3：商业化与提审

- 接入真实激励视频广告位和完整埋点。
- 评估结算翻倍；按数据决定是否接入低频插屏。
- 抖音真机矩阵、包体、弱网、生命周期和合规测试。
- 准备图标、截图、录屏、隐私说明、适龄提示和资质材料。
