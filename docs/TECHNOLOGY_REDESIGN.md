# 科技重设计（1.23.0）

## 用户要求与配置设计

- 研究金币永久投入；删除普通科技重置按钮与退款API，不以隐藏按钮代替删除。旧已购研究保留，不补扣差价，也不清空经营余额。
- 10树50项扩为14树70项：新增首领克制（对首领直击伤害最多6%）、清障技巧（店员清障伤害最多12%）、残骸回收（清障战斗金币最多10%）、补给调度（挑战击退经验最多5%）。保留原有输出与生存上限，扩大成长方向，不把常驻输出再大幅堆高。
- 基础价格改为600／2400／10000／36000／120000，逐分支按原有系数递增；后两级占主要投入。全70项导出审计总价2,981,160金币，不把静态价格当作已验证的游玩时长。
- 修改8原始XLSX：Global、I18、UiLayout、VisualSkin、ArtFrame、TechnologyBranch、TechnologyEffect、TechnologyNode；仍42客户端CSV／manifest。
- TechnologyBranch新增summaryKey，TechnologyNode新增iconKey／briefKey，均为原始表管理的文案／资源引用。新增四个global效果协议，实际数值和累计上限来自TechnologyEffect。

## UI与资源

- 总览：每页六张两列卡片＋一张宽卡，共七方向图标卡片，展示方向、五段进度、下一项与价格，14分支完整填满两页。分支详情：五个带图标、名称、效果提示与状态的节点，通过PNG连线组织；下方展示完整说明和单一研究按钮。
- 不再把科技只有数字的胶囊堆在大面板左侧。卡片、标题横幅和节点徽章使用独立PNG；按钮／面板九宫，图标不拉伸，全部文字Label。
- 内置image_gen逐张制作新横幅、卡片、徽章及四个分支图标，保留源图、提示词、meta、UUID和签名；不切多资源图、不新建图集。
- 文字、坐标、字体、皮肤引用全部由原表导出。逐页Cocos运行截图，覆盖375×667与390×844，不用离线示意图替代验收。

## 接线与验收

- 首领增伤走实际伤害入口；清障增伤只作用于店员攻击障碍；回收只增加原障碍金币，零头跨障碍累计并随开局清空，额外奖励仍只发一次；挑战经验倍率保留小数，不修改补给总次数和候选池。
- 研究仍每局开始取快照；旧存档的历史实付金额仅作记录，不再用于退款。必要检查覆盖永久扣款、旧研究兼容、新四树实际效果、分页和选择／购买；不进行完整通关与点满平衡宣称。
