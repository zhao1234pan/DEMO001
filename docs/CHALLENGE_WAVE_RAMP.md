# 挑战同一波内的难度成长（1.16.0）

用户指出同一波开头守住后，后面会随着建造／升级变简单。1.15.0只有跨波HP成长，同一波175游戏秒内的新怪强度固定。本轮新增波内出生HP曲线，保留波长、跨波成长、金币、攻击与分流规则。

## 配置与算法

ChallengeRule原始XLSX新增两个必填字段，Global原表版本1.16.0；schema、运行校验器、导表校验器、CSV和manifest同步。

|字段|意义|当前值|
|---|---|---|
|phaseHealthGrowth|本波末新入场普通／精英相对本波开头的HP增幅，非负浮点，0显式关闭|21／22／24／25／26为0.55，23为0.2|
|phaseGrowthPower|归一化波内时间的曲线指数，正浮点|全部1.5|

出生倍率为`1 + phaseHealthGrowth × clamp(waveElapsed / waveDuration, 0, 1)^phaseGrowthPower`。普通怪和精英在实际成功入场时读取当前时钟并乘入原HP计算，等待入口不会锁定较早的弱数值。首领继续用独立Wave.bossHealthScale，不叠加该曲线。

一般专题本波50%时间的新怪约增加19.4%HP、75%时约增加35.7%、末端增加55%；仓库专题分别约7.1%、13.0%、20%。成长主要放在后半段。已入场对象的hp／maxHp不会因时钟变化而回满或重新计算，速度、奖励、体型和攻击目标坐标保持。

采用现有游戏时钟：3倍速相应推进，暂停、补给选择、广告阻塞不推进。每波开始重置计时，上一波存活怪保留其出生HP跨波继续前进。下一波开头回到新Wave基础倍率，可能比上一波末端的新怪弱，形成阶段起步窗口；本轮保证波内新怪递增，不宣称跨波每一个出生对象HP都严格递增。

仓库专题0.55及0.3的默认阵容测试均失败，另一个带减速的方案虽可在不同曲线上通过，但本轮将其增幅回调至0.2以保留默认阵容的可行样本。其他专题保持0.55。没有增加依照玩家当前攻击力追涨的动态难度；升级仍应产生可以感受到的收益。
