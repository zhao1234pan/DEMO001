# 独立便利店经营玩法方案

日期：2026-10-11。状态：玩法建议，待用户确认；游戏仍为1.7.4。

用户已经明确：商店要成为可以独立游玩的轻量模拟经营。顾客进店、选货、排队、付款构成自己的经营流程。本文替换此前按战斗波次售卖的方案。冒险首通可以提供新品；商店营业本身由顾客和商品驱动。根据用户最新讨论，本版建议金币留在经营系统，取消兑换战斗道具的方向。具体消费与经营细节仍待确认。

## 玩家进入的是一家正在营业的店

商店打开为固定视角的便利店内景，沿用现有治愈、明亮、圆润的PNG画风。门口、两组起步货架、收银台和动物店员都在同一屏内，顾客会自己走动、拿商品、排队，购买后提着小袋离开。玩家用点按指挥或帮忙完成操作。

顶部显示局外金币和返回入口；货架直接显示商品与剩余数量，顾客头顶用商品图标表达想买什么。下方提供商品、店员、改造和收款几个必要入口。更换商品与升级使用小弹窗，场景里的物体承担主要操作，不把经营页做成密集列表。

每次进入可以玩几十秒到几分钟，想继续开店就继续。店员有基础自动工作，玩家主动操作能改善效率，并观察自己选择的商品是否适合来客。

## 补货和结账带来直接操作乐趣

开店自带一名基础店员，自动处理补货和收银，优先服务正在排队的顾客。玩家点空货架，店员会提箱走过去补货；点收银台，可以帮当前顾客快速结账。搬箱、商品摆满、扫码、金币和购物袋都用简短动画给反馈。

补货免费，库存以货架格数为上限。新手不会因为进货花光金币而停业。玩家点按的是一整次操作，例如补满这一组货架，而不是连点十次逐个摆商品。操作请求不能靠反复点击重复补货或重复结账。

后续能雇佣一个帮手，分开负责理货与收银。店员逐渐接手重复工作后，玩家更多时间用来换货、应对来客和改造店铺。已有店员形象可用于经营岗位，经营雇佣和战斗四人阵容各自管理，不占用出战名额。第一版先区分岗位，经营专属技能后续再设计。

## 选什么货有意义

每个货架放一种商品。起步货架有限，玩家要从已解锁商品中选择搭配。顾客有偏好，有的想买一件，有的会买两件：

- 兔子学生常买面包和牛奶。
- 小熊上班族偏爱饭团和饮料。
- 夜归的小猫喜欢泡面或夜宵。

具体形象和偏好只是草案。顾客想买的商品必须已经解锁；拿齐偏好商品或双件订单时，会多买一件或留下小费。没找到时可以选择现有替代商品，空店才会导致空手离开。这样熟悉的低价商品仍可能靠搭配获得更好收益。

例如只有两个货架，摆两种高价零食可以卖得贵；换成面包和牛奶，则更容易满足学生的双件购买。玩家能从顾客拿了什么、留下多少小费看懂结果。信息由商品图标、购物篮和结账反馈表达，不增加讲解搭配的长提示。

普通客流自动到店。门口另有一次点按的招呼动作，冷却结束可邀请一小批客人。招呼前是否先补货、排队太长时先帮收银还是先扩库存，形成短时间内的选择。第一版先做正常来客与双件订单，再加入招呼客人；不靠持续连点才能维持客流。

## 金币先让自己的店变好

主要成长是可见的门店变化，而非只看收入数字增加：

| 投资 | 玩家得到什么 | 画面反馈 |
| --- | --- | --- |
| 升级货架 | 库存更多，补货频率下降 | 从简单货架变为更整齐的展示柜 |
| 改进收银台 | 自动结账更快，排队减少 | 新收银机、柜台装饰和更利落的动作 |
| 增加货架 | 同时上架更多商品，满足更多偏好 | 店里真的多出一组可使用的货架 |
| 雇佣帮手 | 理货和收银可以同时进行 | 第二位店员在场景里工作 |
| 更换装饰 | 按喜好布置便利店 | 门牌、灯、盆栽、桌边装饰直接换图 |

首版两组货架起步，最多四组。装饰使用固定位置更换款式，新增商店先完整确认布局。正式制作继续遵守独立PNG、相同槽位尺寸和XLSX导表，首页与现有图鉴的用户确认排版继续作为基线。

一个可见目标是先让店铺摆满货，再请一个帮手，随后把空角落变成新的售卖区。顾客购买记录还能增加商品图鉴的累计售出数，商品收集与实际经营发生联系。

熟客、纪念小物和更多主题装修适合后续扩展。第一版先让三类动物顾客拥有能辨认的偏好，场景里有生气即可，不同时新增完整熟客图鉴和大量剧情。

## 局外金币花在哪里

本版推荐把商店做成可独立享受的经营小玩法。金币用来改变这家店的经营方式和外观；暂不开放战斗道具兑换，不增加塔防永久攻击、血量或战斗金币购买。玩家愿意经营，是因为店铺自身有趣，塔防通关不以经营时长为前提。

消费点按玩家得到的体验来选，不为消耗余额新增一串券或材料：

| 消费方向 | 具体例子与回报 | 优先级 |
| --- | --- | --- |
| 设备与店铺成长 | 添第三组货架、改善收银台、加大库存；店里真的多出设备，能同时接待更多来客 | 第一版核心 |
| 雇佣与岗位安排 | 请一个帮手，让收银和补货同时进行；之后换喜欢的动物员工和制服 | 第一版核心 |
| 装修与店员外观 | 从盆栽、门牌、灯具到整套糖果店或雨夜便利店主题；购买后永久拥有、自由换回 | 核心验证后补充 |
| 特色经营区 | 把既有货架槽改成冷柜或热食柜，增加有区别的展示与订单体验 | 后续内容扩展 |
| 自选小活动 | 花金币筹备一次野餐补给、雨夜热食等短活动，迎接特别来客，完成订单留下一件纪念摆件 | 后续候选重复消费 |

首版保留两至四组货架的边界。特色经营区是已有槽位的后续升级方向，不能因为列出候选就同时扩建多个新场景。原型里的已解锁商品均可用基础货架售卖，不要求玩家再购买专用柜才能使用刚解锁的新品。

装修与店员制服只改变外观，普通装饰不增加收入数值，避免每件装饰最后都变成必买属性。整套主题可以分件购买，拥有全套后能一键切换；固定槽位替换独立PNG，保留已经确认的首页、图鉴和其他界面布局。经营制服第一轮只用于店内角色。若以后增加战斗店员皮肤，需要完整覆盖1级、2级与两个进化分支，保留升级辨识度，再单独安排制作，不以一张立绘替换全部形态。

自选活动是可能的重复消费点，回报以新来客、特殊订单、纪念品和不同经营过程为主，不以“花钱买收入倍率”作为主要乐趣。普通营业始终免费，活动不是每日必做任务；活动数值、时长和素材量等原型好玩后再设计，当前不实现，不把它当作长期经济已被验证的依据。

暂不加入付费补货、日常营业门票、设备损坏维修费、商品损耗罚款、随机抽皮肤、纯等待加速券和无限升级。补货仍免费，失败订单不倒扣钱包。皮肤适合作为收集目标，但仅有换皮肤难以撑起经营体验，核心仍是选货、安排工作、应对来客和看着店铺变化。

## 消费节奏的试算

先用前文约20至30金币每分钟的起步收入估计价格，以下以25金币每分钟作比较，均为待原型验证的设计起点，不是已测收入或正式售价：

| 目标 | 草案价格 | 按起步收入估计的累计经营时间 |
| --- | --- | --- |
| 第一次设备小升级 | 60 | 约2.4分钟 |
| 第一个帮手 | 80 | 约3.2分钟 |
| 第三组货架 | 120 | 约4.8分钟 |
| 一件小装饰 | 80至150 | 约3.2至6分钟 |
| 一套经营店员制服 | 400至600 | 约16至24分钟 |
| 一套店铺主题 | 800至1200 | 约32至48分钟 |

这些时间指分多次游玩累积的有效经营时间，不要求连续等待。设备改善后收入会变化，各类消费也会竞争同一余额；正式排表时需要结合真实客流和购买顺序重算。固定数量的设备升级完成后，金币可以继续用于外观和后续内容，不要求给有限体量的小玩法硬加无限消耗。

第一版目标是玩家几分钟内买得起一个能看到变化的升级；后续再给一件较便宜的装饰和一个需要积攒的主题。第一轮不同时制作大量皮肤、特色柜和活动，先验证核心循环。

## 一分钟里的具体体验

玩家进入店内，看见面包架快空、收银台有两位客人。先点货架，店员提着箱子补满；再点收银台帮客人结账，钱进入柜台收款区域。

一位兔子头顶出现面包和牛奶。玩家暂时只卖面包与零食，于是把零食架换成牛奶。之后兔子买齐两件，付款并留下小费。下一次兔子来访时，玩家已经知道它喜欢什么。

货补齐、队伍变短后，玩家点门口招呼来客，看着几个小动物走进店里。攒够钱可以选择先扩货架，或请帮手提高自动处理效率。每次动作都改变店里正在发生的事情，营业可以接着进行。

## 首版数值只用于估计节奏

| 参数 | 原型起点 |
| --- | --- |
| 起始货架与上限 | 2组，后续最多4组 |
| 每架初始库存 | 6份 |
| 起始商品单价 | 3局外金币 |
| 自然来客间隔 | 约10秒 |
| 自动结账耗时 | 约8秒 |
| 主动帮助后耗时 | 约2秒，包含动作等待 |
| 补一组货架耗时 | 约2秒，行走时间另算 |
| 双件订单初始占比 | 约30% |
| 首次小升级目标价格 | 60金币 |
| 第一个帮手目标价格 | 80金币 |
| 第三组货架目标价格 | 120金币 |

以每分钟6位客人、平均购买1.3件、单价3估计，货物充足且完成付款时每分钟约23.4金币；双件订单小费另计。主动经营两分钟目标收入约40至60金币，首个小升级大约两至三分钟可完成。这里没有把额外客流或全部顾客都会成功购买计算为保证收益。

以上是本项目的原型试算，不是参考游戏的实测数值。还要考虑走路、补货、排队和缺货，收入需通过真实原型测试。此前按战斗波次算出的90至135金币收入与补给定价依据作废；本版取消战斗补给兑换建议，经营价格按真实原型收入重新评估。

## 与原有系统的连接

商店首次进入就提供基础商品和开店设备，可以直接营业。此前每关首通解锁一件商品的方向保留为新品来源：建议2件基础商品加20件冒险新品，共22件；具体名称和解锁顺序待统一排表。挑战通关与战斗波次不生成销售额，塔防倍速也不影响商店营业速度。

局外金币用于独立经营的设备、雇佣、装修和外观收集，不兑换战斗补给，不直接累加到战斗金币。新品解锁和商品图鉴是两个系统之间的收集联系；挑战模式按自己的关卡、强化和现有道具规则推进，不要求先在商店攒钱。

第一版先完成在店内营业和离开时保存状态。离线经营、时间上限和自动店员的后台收益下一阶段单独评估，避免在核心体验尚未验证时引入新的等待体系。

## 第一版制作范围

先做一个固定内景、两至三组可用货架、基础商品与首通新品展示、一名基础店员和一个可雇佣帮手、三种顾客、补货、结账、双件订单、小费、收款及两类设备升级。金币从真实顾客付款产生，形成独立的经营循环。

第一轮验证要回答：玩家一分钟内是否有事做，点按是否有直接反馈，选择商品和升级是否能改变经营过程，以及店员接手后是否仍愿意观察店铺。确认这些体验，再扩到四组货架、全商品、招呼客人和装饰。挑战扩关继续保留独立设计，不与这轮经营原型一起改数值。

自愿激励广告可在体验确定后考虑临时帮手或来客团，免费补货、自然顾客和正常营业完整提供。广告适配仍沿用项目已有平台边界，不在设计阶段增加外部服务。

## 配置与存档设计方向

规则确认后，先制作Goods、ShopRule、ShopCustomer、ShopStaff、ShopUpgrade、ShopLayout或复用UiLayout、ShopCosmetic和I18的原始XLSX；商品价格、库存、顾客偏好、订单、行动耗时、奖励、升级、岗位、资源与文案全部导成客户端CSV。现在不把草案数值写进代码。

经营状态保存货架SKU和库存、顾客购物篮、岗位、升级、已购外观、当前穿搭、待收款和钱包。购买设备与外观时原子保存扣款和获得物，重复点击不能重复扣款，已拥有的永久外观不能重复购买。商品取走时预占，真实付款时才产生待收款；每笔交易使用唯一顾客订单号，只提交一次。角色动画回调、页面重开和读档均不得重复发钱。切换商品时已有购物篮价格保持，避免按新价格结旧订单。

商店独立处理营业时间与顾客行为，战斗胜负、波次和战斗倍速不触发经营收入。开店初始状态、已解锁新品和首通迁移另有明确存档规则；GM展示不写正式商品和收入，GM重置覆盖新增经营存档。
