# 独立便利店自动经营方案

## 2026-10-11 用户确认与Demo落地

用户本轮确定首次100金币、面包牛奶自带、其余7件现有商品随第1～7关首通开放、沿用店员解锁再雇佣，并要求增加最多2小时离线收益。以下旧稿“离线不纳入首版”已被此确认覆盖。当前Demo范围和实现见[SHOP_DEMO.md](SHOP_DEMO.md)，22件商品属于后续完整扩展，未放入本次简单Demo。

日期：2026-10-11。状态：用户已确定自动经营与去装饰方向；下述岗位、数值和制作细节为方案，尚未实施。游戏保持1.7.4。

商店是塔防之外的轻量经营小玩法。顾客自动进店、选货、排队和付款，店员自动补货和收银，玩家只在需要时雇佣店员、改进设备或选择商品。去打塔防时商店继续营业，收益自动进入局外钱包。商店金币留在经营系统，不兑换战斗道具。

## 已确定的范围

- 以动物餐厅的动物员工、商品收集和店铺生活感为主要参考。
- 塔防是主玩法，经营不要求持续点按、手动补货、手动收银或手动招揽顾客。
- 不做店铺装饰升级，也不做装修主题、家具收集或自由摆放。
- 保留简单设备升级、经营改进和店员雇佣，已有8位店员都能参与经营。
- 冒险首通解锁商品的方向保留，商店与图鉴共享商品解锁记录；经营收入独立于战斗波次、胜负和倍速。

[动物餐厅官方介绍](https://play.google.com/store/apps/details?id=droidhang.twgame.restaurant)中的动物员工、菜谱和来客体验作为参考。本项目的自动营业、岗位效果和数值是自己的设计；不沿用其家具系统。前一版手动经营、装饰与主题消费方案由本版替换。

## 一家会自己运转的便利店

商店采用固定内景，沿用现有治愈PNG风格。顾客会走到货架拿商品、提着购物篮排队，结账后带购物袋离开。店员自主完成搬货与收银，不需要玩家指挥每一次动作。

第一次进入已有豆包、两组货架、基础商品和收银台，可以直接营业。库存不足时自动补满一批，补货免费；收入自动到账，没有待点按领取的金币堆或收款弹窗。玩家没有金币或暂时不升级，也能继续正常营业。

界面保留局外金币、商品、店员和设备几个必要入口。货架上的商品与数量、顾客购物篮、员工动作和付款动画表达经营状态。点击设备查看改进、点击店员入口雇佣即可，不增加教程弹窗和操作任务。

## 玩家偶尔回来做一次成长选择

玩家看到队伍较长，可以改进收银效率；看到货架经常空，可以增加容量或改善补货效率；想同时售卖更多商品，可以添一组货架；有喜欢的新店员，可以雇佣。

玩家可以自愿更换上架商品，但不把配货做成必须频繁操作的任务。默认配置能正常经营；新品解锁后进入可售目录，有空货架时自动安排合适商品，已有货架不被擅自换货。首次上架与默认推荐规则随后排表，不打断战斗要求处理新品。

每个货架放一种商品，顾客有简单偏好和单件、双件订单。订单只请求已解锁商品，缺少偏好商品时可买现有替代品；匹配订单增加小费机会。商品选择属于低频调整，不要求玩家盯顾客临时换货。已有购物篮的数量与价格在换货或升级后保持原订单。

例如玩家雇佣薄荷并改善货架，随后返回塔防。下次回店，薄荷在自动补货，顾客仍在购买，余额已经增加。玩家可用这笔钱请下一位店员，或改进收银台，再继续挑战。

## 八位店员都能参与

经营雇佣与战斗四人阵容分别保存。可雇佣候选沿用现有Staff解锁条件；雇佣一次永久有效，没有工资、疲劳和每日续费。豆包开店自带，其余7位用局外金币陆续雇佣。

所有已雇佣店员的经营作用持续生效，不限制为四位经营出战，不要求手动排班。为控制画面拥挤与资源成本，店内同时展示约3至4位，其他员工在后场工作，自动轮换仅为表现，不能因为没有显示立绘就失去效果。轮换也不能重复叠加收益。

| 店员 | 简单经营分工建议 | 影响现有经营规则 |
| --- | --- | --- |
| 豆包 | 基础收银与营业 | 开店自带，保证无人操作也能完成补货与收银 |
| 棉棉 | 冷藏商品照料 | 冷藏类商品售价小幅提高 |
| 布丁 | 商品打包 | 双件订单出现概率小幅提高 |
| 咕咕 | 顾客服务 | 小费概率小幅提高 |
| 栗栗 | 设备协助 | 收银与补货工作效率小幅提高 |
| 烘烘 | 热食照料 | 热食类商品售价小幅提高 |
| 薄荷 | 理货补货 | 自动补货耗时下降 |
| 啾啾 | 门口接待 | 自然来客间隔适度缩短 |

这些分工复用售价、订单概率、小费、工作耗时和来客间隔，不另外制作八套小游戏、技能按钮或岗位材料。具体加成幅度等自动经营原型验证后确定；初期没有对应商品类别的员工不会提前开放雇佣，商品与角色解锁顺序需共同检查。

同类效率相加后统一计算耗时，例如基础耗时除以一加总效率；不把多个减时百分比直接扣到零。概率设上限，商品报价在取货时确定并只取整一次。基础营业数值包含开店自带豆包，不能再重复计算一份基础效果。

## 金币只承担几类清楚的用途

| 消费 | 玩家得到的变化 | 首版范围 |
| --- | --- | --- |
| 雇佣店员 | 新角色参与营业，有一项易懂的经营作用 | 覆盖现有8位店员 |
| 改进收银台 | 自动付款更快，队伍减少 | 有限档位升级 |
| 改进货架与补货 | 容量更大，补货更顺畅 | 有限档位升级 |
| 增加货架 | 同时售卖更多商品 | 两组起步，最多四组 |

设备改进使用已有固定场景槽位，不做家具摆放、主题装修或逐件装饰升级。功能升级主要用设备状态、商品数量和角色动作体现，少量必要PNG状态资源保持同尺寸替换。

店员皮肤可以保留为后续可选收藏，本轮不制作、不用于数值加成；也不借皮肤重新加入店铺装修系统。特色经营区与自选活动不进入首版，不预留一串暂不可用入口。先用现有商品、8位员工和有限设备成长验证这家店是否值得回来看看。

不为了消耗金币增加维修费、付费补货或无限升级。商店是有限规模的小玩法，玩家可以逐渐完成成长目标。金币不购买塔防永久攻击、血量或战斗金币，挑战仍按现有规则游玩。

## 自动营业时间

第一版在游戏前台运行期间持续营业，玩家在首页、图鉴或塔防战斗中都按同一经营时钟推进，战斗暂停和倍速不影响商店速度。商店页面负责呈现营业过程，不负责决定是否产生收入。

应用退后台或关闭后暂停营业；关闭游戏后的离线收益本轮先不加入。这样玩家可以专心打塔防，无需挂机看商店，也不用同时引入离线时间上限和领收益广告。

店外不渲染顾客和员工，经营状态按相同订单与付款规则推进。回店恢复当前状态，允许显示简短收益汇总，但到账不依赖打开或确认汇总。不能回店再把已经到账的收益发一遍。

## 首版节奏试算

以下均为自动经营原型起点，正式数值需在XLSX中设计并实测后导出。此前主动点按两秒结账、主动经营两分钟收入等预算不再使用。

| 参数 | 草案起点 |
| --- | --- |
| 货架 | 起始2组，最多4组 |
| 单架初始库存 | 6份 |
| 起始商品价格 | 3局外金币 |
| 自然来客间隔 | 约10秒 |
| 基础自动结账耗时 | 约8秒 |
| 单次自动补货动作 | 约2秒，行走另算 |
| 双件订单初始占比 | 约30% |
| 第一次设备小升级 | 60金币 |
| 第一个付费雇员 | 80金币 |
| 第三组货架 | 120金币 |

每分钟6位来客、平均购买1.3件、单价3，在全部完成付款时约23.4金币，小费另计。这是客流和商品价格的理想试算，不是实际自动收益；补货、行走、排队和缺货都会影响成交。原型先以每分钟约18至24金币为观察目标，第一笔小升级约需2.5至3.3分钟、首个雇员约需3.3至4.4分钟。

七位付费雇员可先按80、140、220、320、440、580、740的价格序列试算，总计2520金币。此序列暂不绑定具体角色；正式雇佣顺序与现有冒险解锁顺序一致后再排表，不能同时卖给玩家尚无对应商品作用的雇员。后期收入会随员工和设备提升，不直接用初始收入预测全部成长时长。

新增货架、收银效率和来客加成需要一起测量：客流增长不能远超可处理能力，雇佣后应能观察到变化。第一版不为每件商品再做星级、熟练度或独立升级树。

## 商品图鉴与塔防的连接

保留每关首次通关解锁一件便利店商品的方向。建议2件初始商品加20件首通新品，共22件，名称与顺序还需统一排表。当前游戏只有9件既有图鉴商品，22件是后续目录方案，不能当作已实现。

商品图鉴与商店共享商品ID、资源和解锁记录；图鉴可显示累计售出数量，解锁后能在店里真实售卖。重复通关不重复解锁或送经营金币。挑战通关、波次和战斗倍速不直接发经营收入。

塔防提供新品与店员候选，商店提供独立经营成长与角色日常表现。经营余额与战斗内金币独立，当前首页与图鉴已确认排版不改动。

## 配置和验证安排

实施时先设计原始Goods、ShopRule、ShopCustomer、ShopStaff、ShopUpgrade及必要UiLayout、I18字段，经项目导表校验生成客户端CSV。商品类别、售价、顾客偏好、工作耗时、雇佣条件、加成、价格和资源全部配置管理；本轮不制作原始表、不改运行参数。

经营只由一个状态服务推进，页面创建和销毁不能创建第二份营业计时器。动画回调只表现结果，不决定发钱。顾客订单使用唯一ID，取货预占库存，成功付款原子保存订单完成、销量和钱包。

购买时先推进并结算到购买发生时刻，再原子保存扣款和员工或升级；新加成不追溯影响此前收益。重开页面、快速购买、反复换页和恢复存档均不得重复发钱或扣钱。GM预览不写正式收入，重置进度同时清理经营存档。

第一轮做一个固定内景、基础商品与首通新品、三类顾客、完整自动补货和结账、现有8位店员的简单经营作用、两类设备改进及最多四组货架。先验证无人操作能营业、打塔防期间能正常推进、回店不重复结算、员工与设备能改善体验，再决定是否制作皮肤或其他内容。挑战扩关仍作为独立任务推进。
