## 本轮实际改变

1. 文字采用10/12/14/16/18/20/24/28/32设计单位阶梯；常用正文14、操作16/18/20，说明行保留行距。首页、图鉴既有确认稿和隐藏的启动错误文字模板单列保留。移除其余固定文字的自动SHRINK；纸面正文清除描边，彩色操作保留细描边。
2. 补给仍为三列竖卡、每张独立图标、专属店员行和一次广告刷新；卡片加高，最长说明拥有固定字号的独立空间。已持有列表和待选列表的分页/刷新互斥。
3. 经营管理条目采用同一奶油薄荷矩形卡，头像、名称/完整岗位说明、购买/不可用状态分别占列；扩大三行管理窗和行距。顶部小钱包使用千/万/亿/万亿，管理余额与扣款仍是精确原值。
4. 科技总览与详情采用同一种薄荷卡，不再把三行小字挤进金属横框。标题/效果在左，费用/解锁条件在右；选中仍使用同一PNG。五层节点和七张总览的等大规格保持。
5. 图鉴详情采用固定标题/关闭、PNG裁切内容区和内部滚动，长说明按真实Label行高增长，不再整体缩小详情。内容区外不能点到滚出去的等级/制服按钮；切条目、关闭、短内容恢复顶部。
6. 冒险/挑战分页加高并留内边距；挑战专题为最长规则预留三行；补齐排行榜进度、建造卡、首领信息、来客预告、结算、设置和通用控件的行框间隔。

全部原表修改先进入UiLayout/Global/I18 XLSX，再导出CSV/manifest与Prefab；原PNG、PNG.meta及39份业务CSV保持。只从已入库授权源字体补齐新增单位字，不更换字族。

## 验证与证据边界

必要回归包含配置、资源、图鉴、经营交互、榜单、战斗操作、挑战、科技、经营模拟、跨控件边界和本轮文字/金额规范。新增详情滚动及裁切后不可穿透点击的回归；字号检查不只看外框。

离线字形测量、原尺寸组件校样与前后对照用于内部自检，见`docs/evidence/ui-experience-20261031/`。使用实际Prefab/PNG/授权字体及实际呈现代码的隔离状态，未读取玩家真实存档。字体换行和PNG渲染仍可能与Cocos不同。

先前浏览器URL安全限制继续遵循，不用另一浏览器、CDP或原生自动化绕过；没有把本轮离线校样称作引擎截图或手机通过。390设计宽下的字号不等于所有设备上的最终CSS字号；整个棋盘仍沿用原有等比适配，320×480短屏及宿主安全区需要实屏复看。

用户追加授权只更新TapTap自测包，不提审、不上线。使用正式DEBUG=false构建，记录来源提交、包体SHA与官方工具实际返回；未拿到上传结果前不记作平台已更新。平台授权失效时需用户扫码，不能读取其他项目的令牌代用。

发布前补查三商品组合、最长商品位与最大安全整数余额，共1438份文本样本/1406份固定框测量；加宽精确余额与收益提示，货架底板承托完整名称和库存。最终646条布局记录变更。
