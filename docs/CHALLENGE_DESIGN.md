# 固定挑战体验关：分析、配置与实测

## 设计结论

首版提供一张固定体验地图，点击首页挑战直接进入；最终21波，限定棉棉（减速）、布丁（范围伤害）、咕咕（远程贯穿）、薄荷（团队增伤）。用控制、范围火力、重型目标输出和增伤建立搭配价值。地图复用第10关双回廊，独立mapId=21；22格包括10个需要清障的位置，占用率按全部22格统计，目标约80%且部分升级，不设占用率强制胜利条件。

先按用户要求做设计分析，再写原始表；初稿24波的隔离模拟耗时879.6～1031.2秒且几乎铺满升满，不符合目标，已改21波、缩短队列、0.3秒组内间隔，并调整14波首领和21波双首领压力。初始金币410、关卡血量倍率3，前3波0.6、4～6波0.8、后续1的本波血量倍率；基础移速始终读取Enemy表。所有这些值来自XLSX/CSV。

广告道具每种一次：金币帮助提前上岗，冷气延长输出窗口，清场处理危险队列且按原有首领折损比例结算。失败、取消、缺广告位和浏览器模拟不发奖；没有必须看广告才能结算的代码条件。挑战胜败、重开与返回不写冒险解锁/最高关。

铺开策略19/22=86.4%，其中10～11人有升级，接近约80%目标；广告显著改善该策略的血量余量。优先少量店员升级的混合策略无广告末波失败，三道具后1血通过。纯咕咕固定策略仍可1血过关：首版鼓励搭配并提高容错，不宣称已证明“所有单一阵容不可能通关”。没有用强制观看或限制胜利的方式制造难度。

测试为确定策略驱动真实GameRoot，画面/音频设备/存储为隔离替身，广告成功是明确注入测试回调。8～12分钟按1倍速、等待全部准备倒计时统计；主动提前开波会缩短时长。该结果用于初次体验校准，不代表真人胜率；后续以用户实玩反馈微调搭配和数值。

## 首版边界

每日轮换、跨日刷新、服务端时间、排行榜、额外奖励和账户系统均未纳入。仅固定体验关，不更改冒险20关终点；真实宿主广告位和手机触控仍需现场验收。
