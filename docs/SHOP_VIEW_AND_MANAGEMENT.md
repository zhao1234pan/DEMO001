# 商店视角与管理入口 1.8.1

- 用户反馈：原室内透视与图鉴展示板不一致，商品像悬浮；底部管理占用过多空间。
- 改为高俯视斜角便利店：独立完整地板、落地双层货架和收银台PNG，2×2货架留中央过道，六个独立商品槽按实际库存显示。
- 顾客沿入口、中央过道、货架前方、收银区移动。所有地面节点按脚底坐标排序；经营结算继续由ShopSimulation独立推进。
- 默认仅保留管理按钮，点击弹出雇佣店员／设备改进／商品上架列表，再进入对应明细。支持关闭、遮罩返回、明细返回列表；面板空白截获点击，防止误触底层货架或返回。
- 商品明细可选货架；当前商品显示已上架，避免重复点击刷新库存。收银区下移，弹窗时GM移到底部。
- 原始UiLayout、VisualSkin、I18、ShopPoint、ShopRule、Global与CSV、manifest同步，圆体新增字符子集同步。原内景留档。经营价格、礼金、离线、升级、解锁、已有存档和首页确认排版不变。
