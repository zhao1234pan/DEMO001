## 1. 产品目标

《叮咚夜班开始》是一款面向抖音及微信小游戏的竖屏轻量闯关塔防；两平台分别验收。设计重点是：

- 打开后快速理解，不依赖长教程。
- 单手点击，战斗自动进行。
- 单关短、失败反馈快、可以立即重试。
- 通过敌人组合和少量关卡事件制造难点。
- 道具和激励视频提供明确、可选择的救援，不制造只能看广告才能通过的关卡。

不把三消、整理、合成或经营做成并行主玩法。首版的唯一核心是塔防。

## 2. 核心循环

```text
首页继续闯关或选择已解锁的第 N 关
→ 观察路线、空地和可清除障碍
→ 点击有效空地并在附近选择店员建造
→ 店员自动攻击、自动获得局内收入
→ 在安全窗口指定店员清障，获得零钱并释放新空间
→ 点击已有店员进行升级或出售转移火力
→ 按需要切换 1、2、3 倍战斗速度
→ 危险时使用一键道具
→ 守到最后一波后进入下一关或返回首页
→ 失败时免费重试或主动选择广告救援
```

## 3. 单关结构

- 初始目标时长：60～120 秒。
- 当前波次：第1～9关4波，第10关5波；自动开始，不要求手动放行。未来是否增至5～8波由试玩决定。
- 首波先保留开场布置时间；波间先显示守住奖励，再显示入口数字倒计时。
- 当前地图：一条清晰路线，22个离散建造单元；12个开局可用，其余10个由可清除障碍占据。
- 未来单关最多加入一种特殊事件；当前十关未加入事件。
- 通关后提供“下一关”和“返回首页”；第10关保留“再次挑战”，不做星级评价或新增全通标记。
- 失败后提供广告继续、免费重新挑战和返回首页；广告次数与规则沿用现有实现。

以上数量是首轮原型目标，可在试玩后调整，但不得通过叠加额外系统延长单局。

## 4. 基础操作

1. 点击路线外的有效空地，系统吸附到最近合法建造单元，并在附近显示本关可用的店员。
2. 点击店员按钮完成建造；零钱不足时按钮变灰并给出提示。
3. 点击已有店员，显示攻击范围以及跟随塔位的升级、出售按钮。
4. 点击可清除障碍物，将其设为清障目标；清除后获得零钱并释放建造单元。
5. 点击升级或出售完成操作；点击空白区域关闭当前菜单或取消清障目标。
6. 点击道具按钮，立即产生全场效果。
7. 点击顶部倍速按钮，在 1、2、3 倍之间循环切换；暂停时也可预设恢复后的速度。

首版不提供拖动换位、技能瞄准、分支升级和手动开始下一波；出售只返还部分累计投入，避免无损搬塔。

### 首页、返回与正式进度

- 首页展示“已解锁 N / 10 关”；此数字表示可进入的最高关卡，不等于已通关数量。第1关初始可用。
- “继续闯关”始终进入最高已解锁关卡；选择低关重玩不改变该目标，不保存“上次点了哪关”作为新进度。
- 只有正式通关解锁下一关，取现有解锁与本关下一关的较大值，上限为第10关；失败、重开、回首页和GM演练不降低或冒增正式解锁。
- 暂停页按钮明确写“结束本局并返回”；结算页使用“返回首页”。再次进入关卡从开局开始。返回后清除本局战斗对象和操作选择，首页不推进波次或战斗计时。
- 首页选关与战斗继续使用统一触点取消、按钮绘制/命中和安全区布局规则；锁定关卡同时显示未解锁状态，不只依赖颜色区分。
- GM“返回正式进度”现在回首页；MapReview仍跳过玩家首页用于固定视觉评审，不写入正式进度。
- 关卡配置入口将非有限值回退到1、有限小数向下取整并限制在1～10；存储空白或不可解析值采用默认值。倍速仍只接受1、2、3。
- 最高解锁与既有最高关纪录在保存时，将本次值、会话值和旧存档向下取整、夹到0～10后取最大值。旧存档读取失败时保留会话值并暂不落盘；下次读取该键时重试合并和保存，防止用较低会话值覆盖更高旧档。实际进关仍通过配置入口限制在1～10。
- 倍速按新选择保存，允许降速，不使用最高值合并；普通存储读异常可回退至会话最近有效值，写失败优先保留会话待落盘值。
- 没有后台定时重试；最高纪录在下次读取时尝试恢复。这不是云存档、存档迁移或局中恢复，不保证关闭进程后保留尚未成功落盘的数据。

### 当前UI卡片与道具尺寸

- 下述单位为390宽棋盘的逻辑像素，换算到750宽设计分辨率需乘以750/390；不把逻辑尺寸误当成最终设计尺寸。
- 右下三个常驻道具底板各88×64，左边界分别为x=92/188/284、横向间隔8；道具透明图标画布45×45，名称/次数位于底板下部，绘制与点击共用位置和尺寸配置，热区再按最小触控尺寸处理。
- 建造店员卡片为64×84，提供角色缩略图、名称和价格；升级/出售按钮为96×48，保持就近操作。
- 三个道具图标共享512×512透明图集，按192×192独立帧取图；图标与卡片底板分离，文字不烘焙进图片。
- 顶栏高度72，常规可交互按钮最小热区46×46；动态安全区与极短安全区的退化规则仍以实际布局代码及真机验证为准。

### 波次预告规则

- 提示贴近本关怪物入口，显示“下一波 当前波次/总波次”和剩余数字，让玩家同时知道时间与出怪方向。
- 开场、波次奖励和复活提示优先展示；提示结束后再进入数字倒计时，期间仍可建造、升级或使用道具。
- 倒计时属于战斗时间，受 1、2、3 倍速影响；暂停、切后台和广告期间停止推进。

### 战斗倍速规则

- 倍速同步影响敌人移动、店员攻击、投射物、波次等待、道具效果和战斗表现计时，不改变伤害、收入或掉落数值。
- 暂停、切入后台和请求广告时停止战斗时间；胜负结算不受倍速推进。
- 玩家选择写入本地偏好，切关、重开、复活和再次启动均保留，并始终作为正式功能向玩家开放。

### 战斗反馈与音效规则

- 豆包、棉棉和布丁使用不同的攻击色彩、炮口方向、后坐与短火光，命中敌人时提供短暂闪烁，击杀时显示更明显的爆点。
- 建造和升级在对应塔位附近显示短文字；漏怪时战场短暂红闪，并在终点附近显示耐久损失，帮助玩家理解失败原因。
- 建造、升级、三种攻击、击杀、漏怪、道具、波次开始和胜负结算均有独立短音效；同类高频声音设置最小间隔，避免密集波次形成噪声。
- 音效使用 Cocos 原生资源与 `AudioSource` 播放，不依赖浏览器 DOM；加载失败只跳过本次声音，保证 Web 与抖音小游戏战斗流程一致。
- 本轮不加入新手引导；先依靠熟悉的点击操作、上下文按钮、倒计时和即时反馈降低理解成本。

## 5. 地图与塔位规则

- 前 10 关不重复使用同一路线，入口方向、折返方式和关键弯道逐步变化。
- 十关当前均配置22个潜在建造单元；空位与障碍共用连续地台中的浅方格，选中时强化反馈，不用一圈圈椭圆底座割裂成组关系。
- 每关12个单元可直接建造、10个由障碍占据；正常通关预计建成8～12名店员仍是待人工验证目标，不强迫满建。
- 所有空位和障碍占位共用50逻辑像素网格，x=45～345、y=135～585；每格至少有一个正交邻格，每关收束为3～5组连续排、列或折角，不用边缘孤点凑22格。
- 点到道路中心至少45、相邻建造中心至少50；每个塔位的豆包基础射程有效路径覆盖至少90，使用解析线段与圆相交计算，不再用4像素步长采样。当前十关最小实际覆盖约为第9关94.13，其余关最小值约110.42。
- 每组均保留开局开放格，所有障碍存在本关一级可用店员的清障链；高价值格既有直接开放，也有通过清障获得，不把所有强位免费堆在入口。
- 所有塔位中心满足y≥135，为店员三级精灵的头顶与0～72顶部状态栏保留净空；不保留旧y=85塔位，也不通过单独缩小顶排角色规避遮挡。
- 建造单元必须与道路、障碍物和邻近单元保持足够间距，不能因提高数量造成角色、按钮和攻击表现互相遮挡。
- 入口/终点是屏内真实路径首尾，不再让怪物走隐藏的屏外尾段。地标图片为64×56、中心在路径点y+6；结合上方文字，联合框为x±32、y-40～y+34，须完整避开顶部HUD与底部道具，并与三级店员最大画布保持净空。
- 至少形成入口、拐角、长直线、终点前和多段道路重叠区等不同价值的布阵位置。
- 可清除障碍物必须同时承担空间、经济和节奏作用，清除后释放对应单元并给予可预测零钱。
- 每关至少提供两种可通关布阵，避免只允许照固定顺序点击。
- 路线长度控制在约 1000～1650 个逻辑像素；再通过敌人速度倍率修正实际通行时间。

## 6. 店员体系

### 规模规则

- 首发版本：豆包、棉棉、布丁三名店员。
- 长期角色池：计划扩展到 8～12 名。
- 单个关卡：只提供 3～4 名可用店员，避免战斗界面复杂化。
- 前期关卡：由关卡直接配置可用店员，不要求玩家提前编队。
- 后期是否增加简单编队，在基础玩法验证后再决定，不属于首版范围。

### 首发店员

- 豆包：快速单体，处理普通和高速敌人。
- 棉棉：减速控制，延长敌人在攻击范围内的时间。
- 布丁：范围驱赶，处理密集敌群。

每名店员首版最高三级，只强化已有定位，不加入技能树。

### 后续扩展原则

新店员必须带来新的战斗作用，不能只是数值更高的旧角色。可扩展方向包括：

- 阻挡或短暂封路。
- 超远距离或优先攻击特殊目标。
- 持续范围伤害。
- 提升附近店员攻速或攻击力。
- 穿透、弹射或连锁攻击。
- 发现隐藏敌人或解除特殊状态。

建议每 5～10 关最多引入一名新店员，让玩家一次只学习一个新能力。

## 7. 三个一键道具

### 冰柜冷气

- 一键冻结全场敌人。
- 初始效果目标为 5 秒，最终时长由测试决定。

### 闭店清场

- 立即赶走屏幕内的普通敌人。
- 对精英敌人造成大量伤害，不直接秒杀关卡首领。

### 紧急零钱

- 立即获得一笔局内收入。
- 用于紧急建造或升级店员。

三个道具均不需要拖动、瞄准或二次确认。免费库存与广告补充次数后续配置化；首版原则是每种道具每关最多通过广告补充一次。

## 8. 敌人与难度

首版使用三种基础敌人：

- 普通型：速度和耐久均衡。
- 高速型：生命较低，快速冲向便利店。
- 重型：移动慢、耐久高，为后方敌人争取时间。

难度优先来自出场顺序和组合，而不是单纯提高生命值：

- 普通敌人后突然加入高速敌人。
- 重型敌人在前方吸收攻击，高速敌人从后方跟进。
- 最后一波形成数量明显增加的抢购潮。

玩家应能理解失败原因，并可通过调整塔位、升级顺序或使用道具解决。

## 9. 特殊事件

特殊事件是唯一保留评估的额外关卡变化，一关最多一种：

- 抢购潮：短时间出现更多敌人。
- 停电：店员短暂停止攻击。
- 大雾：店员攻击范围暂时缩小。
- 加急配送：一个塔位暂时不可使用。

事件触发前必须给予清楚的文字和视觉提示。这些是后续候选，当前十关未实现；0.5.0基础功能轮次不加入事件，是否制作需另行确认。

## 10. IAA 救援边界

以下为目标规则。0.5.0按用户要求维持广告实现现状；缺广告位直接奖励、异常状态复位及正式ID接入仍待后续任务，不把模拟奖励或免费道具自动演练当作真实广告/发布验收。

### 失败复活

- 每关最多一次。
- 保留已建店员，恢复部分便利店耐久，清掉当前波的敌人/投射物/待出怪队列并重打当前波次。
- 免费重新挑战始终可见，不把广告作为进入下一关的唯一条件。

### 道具补充

- 道具库存为零时，玩家可以主动观看激励视频补充一次并立即使用。
- 广告失败、无填充或未完整观看时不发放道具，但不得阻断免费重试。

首版不接入强制插屏、结算翻倍或多广告连续观看。其他广告点位必须等真实数据后再评估。

## 11. 第一版内容范围

- 首页、最高已解锁关卡入口、已解锁关卡重玩与暂停/结算返回首页。
- 10 个连续编号关卡。
- 豆包、棉棉、布丁三名店员。
- 普通、高速、重型三种敌人。
- 冰柜冷气、闭店清场、紧急零钱三个道具。
- 10条独立路线，每关22个规则建造单元、12个开局空地和10个可清除障碍物。
- 建造、三级升级、部分退款出售、障碍物指定攻击和清障释放空间。
- 特殊事件只作后续候选，本轮不实现。
- 一次失败广告复活和道具广告补充接口。

明确不做：星级、补货小游戏、三消、合成、装修、图鉴、每日任务、装备、技能树、复杂章节地图和长篇剧情。

## 12. 待原型验证

1. 单关 60～120 秒是否有足够的策略反馈。
2. 每关 3 名还是 4 名可用店员更清晰。
3. 20～24 个建造单元是否在手机小屏幕上清楚可点，正常成型的 8～12 名店员是否产生足够布阵选择而不拥挤。
4. 三个道具的免费库存、效果强度和广告补充频率。
5. 第一个新增店员应提供哪一种新机制。
6. 特殊事件是否真正提升乐趣，还是增加理解成本。
7. 清障奖励、释放空间和出售返还比例是否形成策略，而不是固定最优点击顺序。
