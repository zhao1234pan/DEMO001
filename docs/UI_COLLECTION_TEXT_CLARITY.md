## 字体采样

Cocos 3.8.8的TTF实现按view缩放生成字纹理。此前750设计坐标和390逻辑坐标之间还有父节点放大，Label纹理没有计入这层额外放大，导致文字更容易发糊。

运行视图改用390逻辑宽度，保持750比1334的原始比例与原有画面实体尺寸。字体文件、字号、字色和用户布局保持；屏幕尺寸变化后更新Label纹理。触点和动态文字的原设计像素下限同步换算，避免清晰度修复连带改变按钮热区。

这是引擎采样修复。静态几何对比通过，不等于所有设备上的文字已经目视验收；当前工具策略阻止本地浏览器检查，真实高DPI和手机表现仍需补验。
