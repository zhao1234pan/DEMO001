## 保留的产品与玩法决定

- 名称《叮咚！夜班开始》，森林夜班便利店主题，小浣熊店长；轻松动物、简洁Q萌风格。
- 唯一核心是轻塔防：建造、三级升级、清障扩张、65%累计投入返还出售、连续闯关。
- 首发三店员，未来可扩展8～12名，每关仅提供3～4名；前三关依次解锁单体、减速、范围输出。
- 三个局内道具、正式1/2/3倍速、暂停、出怪预告、胜负和本地进度；11个原创合成短音效。
- 不增加星级、补货小游戏、三消、合成、复杂局外养成；新手引导暂不制作。
- 广告按用户最新要求维持现状。本轮没有更改SDK调用、发奖规则、次数或缺配置行为。
