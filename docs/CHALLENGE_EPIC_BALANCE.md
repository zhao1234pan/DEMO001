# 挑战长局与怪潮重调（1.13.0）

用户目标是3倍速实际约15分钟、持续大量怪群、约80%塔位投入，并且需要升级和合理选择科技。六个专题仍各15波、10次三选一，5／10／15波有首领，地图与冒险20关保持。

## 波次和经济

- 普通怪每波450逐渐增至700，组间保留各专题原怪物比例，间隔0.25游戏秒；整局约8,630名。首领插在对应波约60%出怪处，后续怪群继续进场，避免首领单独站场被“最后一位”轻易消化。
- 准备10真实秒、波间3真实秒，沿用独立准备时钟；3倍速只加速战斗时间，选卡期间停表。下表时间不包含真人思考、暂停、广告或帧率不足，因此真人实玩可能更长。
- 普通怪血量按波次平方曲线增长。夜班试营业0.6→6、急件0.5→3.2、清点0.6→6、零钱0.3→2.8、迷你0.6→10、压轴0.6→6；这里是Enemy基础HP的倍率。不同路线与怪种分别调节。
- 首领原血量倍率×1.1，移动速度×0.65，压轴×0.55，提供升级阵容持续集火的窗口；普通怪基础移速不改。
- 初始金币650；击败奖励按原基础及零钱科技收益的5.5%逐次累计小数后发整数。否则怪群增加约30倍会直接送满金币、抵消难度。波次补给、券与利息仍沿用原规则。

## 科技收敛

|科技|调整|
|---|---|
|持币增伤G04|每100金币增伤10%→2%，上限40%→20%|
|远程增伤S04|60%→35%|
|最后一位X06|80%→40%，仍只在全波出完且剩一名时生效|
|余温S06|半径65→56、灼烧倍率200%→120%，最多影响最近6名，阻止密集怪群无限放大附加伤害|

普通店员和进化基础攻击规则保持，科技仍提供组合收益。局内金币不进入便利店钱包；便利店金币长期方向见[经营金币设计](SHOP_COIN_DESIGN.md)，本轮没有实现新的永久解锁交易或局外战力加成。

多项攻速叠加后的最短间隔由基础40%收紧至60%，避免科技把攻击频率过度放大；该下限仍由ChallengeRule.minIntervalRatio原始表管理。

另查种子7全图六专题全部获胜，859～930秒。现有战斗采用小步拆帧，出怪与攻击仍有帧步取整差异；60帧步进的21／26八成策略879／871秒胜利，23／24八成策略第15波失败，多一个塔位（18/21、19/22，约86%）后858／820秒胜利。成功局观察范围13:40～15:30，不能把30帧表格作为每台设备严格固定的900秒承诺；本轮没有修改全局战斗计时算法。

旧版本默认自动策略仅192～229秒、247～296来客、峰值12～20；旧21／24／26专题半图策略也能获胜。旧基线策略未统一八成上限，不能把它当成与新版逐项同条件的胜率实验。原始报告、全图复验与其他种子结果见[证据](evidence/challenge-epic-balance-20261017/README.md)。
