# 可复用经验条目

版本：2026-11-12.1。下表按各分支复盘提炼；具体次数、日期、数值和平台状态仍属于原案例，不作为其他项目的保证。

| 编号 | 反复出现的问题 | 后续执行与验收 |
| --- | --- | --- |
| E-GAME-01 | 功能很多但玩家不知道当前做什么 | 用具体决定和因果链组织首轮流程，连续玩到后果显现 |
| E-GAME-02 | 布阵缺敌阵、装备穿戴不可见 | 决定前展示必要依据，操作后显示真实变化，保持场景连续 |
| E-GAME-03 | 增加特效仍无法辨认机关 | 先修物体轮廓与动作关系，再加材质；显示与判定一致 |
| E-GAME-04 | 选择只有即时加数值 | 后续事件引用真实约定和经历，保留代价、冲突与修复机会 |
| E-GAME-05 | 人物培养不影响用人体验 | 身份约定、培养目标、实际比赛和后续谈话连起来 |
| E-GAME-06 | 普通反馈反复强制打断 | 分清重要决定与普通结果，保留玩家正在进行的节奏 |
| E-GAME-07 | 广告奖励到账却没有价值 | 同策略比较实际用途、等待、操作和完成时间，检查后期 |
| E-GAME-08 | 重玩重复报新解锁 | 按存档前后真实差异及首次事件判断，隔离 GM 与正式进度 |
| E-UI-01 | 全局模板让游戏同质化 | 统一制作方法，按各游戏题材固定自己的视觉语言 |
| E-UI-02 | 外框没超界，字和图仍压边 | 检查实际字框、PNG 安全区、非透明轮廓与视觉中心 |
| E-UI-03 | 布局变化保留旧状态 | 完整接管位置、透明度、对齐、事件与节点池状态，反复往返 |
| E-UI-04 | 小字、截断和整页缩放掩盖空间不足 | 去重、改结构、分页或必要内部滚动，关键动作可达 |
| E-UI-05 | 自检册替用户填通过 | 保留原意见、普通/短屏新图、旧图、结论和导出，用户确认另记 |
| E-ENG-01 | 迁引擎后逻辑通过但运行失效 | 小切片验证生命周期、遮罩、资源序列化和真实产物 |
| E-ENG-02 | Map/Set 在目标编译器展开错误 | 用兼容写法并在 Creator 产物测资源、伤害与寻路 |
| E-ENG-03 | 发布资源与原图、CSV 不一致 | 保留源与派生清单，构建前检查过期，入包逐项核对 |
| E-ENG-04 | 节点和文字重建造成卡顿 | 先测实际战斗，再有界复用，不合并真实数值事件 |
| E-ENG-05 | 交易确认时条件已经变化 | 重算清单与签名，资源一起保存，失败恢复完整事务 |
| E-ENG-06 | 旧页覆盖新进度、广告欠奖 | 唯一请求与版本隔离、持久化依据、多实例和恢复验证 |
| E-ENG-07 | 长档优化靠删历史或放宽配额 | 无损协议、完整回放/备份、展开一致与关键写入点故障恢复 |
| E-ENG-08 | 模拟到达不代表界面解锁正确 | 连续规则长跑与实际客户端门槛检查分别保留 |
| E-ENG-09 | 校验期间覆盖原表，读到半写ZIP而误判损坏 | 候选校验后原子替换；Windows占用安全重试；固定输入快照后导表与复测 |
| E-COPY-01 | 格式和图数通过仍漏内容 | 配置与入口生成覆盖表，对应章节、图号和最终页码 |
| E-COPY-02 | 胜利图是直接设置状态且数值矛盾 | 用完整实际流程证据，核对波次、资源、击退和结算 |
| E-COPY-03 | 新版截图混入旧版登记材料 | 固定标签解析提交、配置与构建，原件保留，改软件另记 |

| E-COPY-07 | 代码量混入依赖、重复核心和排版续行 | 完整有序源码先核对，再摘录；统计口径、来源分别说明 |

| E-WX-03 | 包能导出但手机按钮被视频盖住 | 在真实宿主验证原生层级，错误时保留可用底图与操作 |

| E-WX-05 | 压缩变小但字体或图像坏了 | 发布副本处理，原尺寸/UUID/九宫保留，当前字符与画面复验 |

| E-WX-08 | 版本上传、体验设置、审核和发布混为一谈 | 各阶段读回并记录，普通用户正式入口最终验证 |
| E-WX-09 | 单机被描述成首次完全不联网 | 分清首次下载、分包、缓存与离线运行条件 |
