# 微信小游戏准备与发行

版本：2026-11-14.2。经验依据：E-WX-01～09，见[经验条目](../EXPERIENCE_REGISTER.md)。本文的后台案例属于当时记录，执行时核对目标账号、当前官方工具和真实后台，不把旧截图当作现在状态。

## 分开核对账号与版本

分别记录主体、名称与类目、认证、小程序备案、小游戏相关资质、隐私配置、开发版、体验版、审核版和线上版本。某一项通过不意味着其他项通过。用户已提供的截图和结论保留，缺少具体处置记录时，不把“搜索受限”一句文案直接解释成内容违规、封号或不能开发。

搜索、分享、公开版本、认证和后台开关分别排查；账号已有明确通知时按通知处理，没有明确原因时请平台核实。不能承诺认证或备案完成后自动解除全部限制，不用换账号或改名规避处置。

先稳定本次名称和主体，再按真实后台处理后续流程；办理中改名、迁主体可能影响既有材料，应先核对。具体审核时间、费用、大小限额和资质要求不作为永久常量抄入本规范。

## 目标产物与身份

Cocos 小游戏构建、普通 H5、单文件 HTML 与网页预览是不同产物。小游戏入口、编译类型、方向、AppID 和运行文件按目标构建检查，不能仅修改 ZIP 名称就替代平台转换。

每个项目使用自己的 AppID、存档命名空间、上传密钥与广告位。参考另一个项目时复用步骤，不复制其身份和权限。上传密钥只保存在项目既有私有位置，工具读取路径；不把密钥放进客户端、共享规范或日志。

本地安装记录不代表开发者工具可运行；构建完成也不代表已在工具或手机打开。记录实际工具、引擎、基础库与产物版本。

## 首屏、分包与资源

区分宿主等待、下载主包、引擎启动、首屏可见、首个操作和后续资源加载。尽早呈现真实加载反馈，分别测量这些阶段；游戏 loading 不能证明宿主黑屏已缩短。

按当前平台规则划分主包、公共资源和地图或内容分包。单机游戏仍可能需要首次下载，不能声称首次运行完全无需网络。包内方案和外部资源服务要明确，发行包中不能残留只在开发机可用的 localhost 地址。

压缩处理发布副本，保留源 PNG、原尺寸、UUID、九宫和字体来源。减色不写成逐像素无损；比较当前文字、缩放、透明边界、纹理和字形。字体子集基于实际内容生成，新增文案后重新生成并验证。记录本地统计、ZIP 大小和官方预览统计各自口径。

首次进入时只准备必要资源，其他内容按已确认的分包方案加载。压缩成功和预览被工具接受，不代表真机画面、内存或完整流程通过。

## 视频与原生覆盖层

首页原生视频层可能覆盖引擎按钮，不能仅凭 Web 中的层级参数认定微信排序相同。实际手机检查进入、按钮、弹窗、切后台和返回。需要引擎内纹理解码方案时，按当前 API 核对帧时间、循环、释放和错误处理。

保留不支持或解码失败时的可用底图与按钮，离开首页或切后台释放对应资源。具体方案属于项目适配，不强制所有游戏采用视频或同一种解码器。

## 输入、音频与存档

至少覆盖短屏与常规屏、安全区与胶囊、横竖屏切换、长列表首尾、按钮命中、双指操作、拖出取消、失焦和前后台。取消不能误扣费用或冷却，页面变化不能重置战局。

音频测试启动手势、音乐和音效开关、暂停、锁屏、切后台、返回和循环边界。无音频资源时明确未完成，不能把静音当成正式音源。

保存检查退出重进、系统回收、失败提示、旧档兼容、重复领取和旧实例覆盖。浏览器 localStorage 的结果不能替代目标宿主存储验证。测试使用隔离数据，不清理用户的真实进度。

## 分享、榜单、隐私与广告

分享卡使用对应版本的真实玩法和正确比例，检查好友、朋友圈及宿主允许的入口。分享接入、正式分享能力可用与用户实际收到分别验证，不把分享返回当成奖励资格。

好友榜按开放数据域和目标接口隔离，朋友原始数据不回传到主域。检查授权、拒绝、空榜、双账号、返回和不同宿主隔离；接口替身不代表真实朋友关系验证。

隐私配置按实际收集和使用的能力核对。删除某个可选隐私按钮不等于免除后台要求，也不因为有平台模板就新增没有用途的采集和弹窗。

广告只有在项目真实开通、适配并验证后才启用。未开通或关闭时隐藏对应入口，不落入浏览器模拟成功路径。完整观看、取消、无库存、失败、切后台、重复与迟到回调、保存失败和恢复分别验证；收益与播放次数另记。

## 材料和发布流程

准备名称、头像、介绍、适龄与实际后台要求的文字图片；图片表达不同玩法模块，不能只靠文件哈希不同证明画面不同。不得在截图上后贴不存在的功能，当前包、画面和说明保持一致。

依次记录：开发包生成、官方工具接受、预览码、开发版上传、体验设置、审核提交、审核结果、发布操作、版本生效、普通用户实际进入。CLI 的上传成功不能替代体验版设置；本地二维码生成不代表用户已扫码通过。

上传 IP 白名单不匹配等错误按目标账号的官方流程处理。预览与上传使用同一版本来源，失败先查询结果再重试，避免重复提交。协议、认证、备案、正式提审与发布各按当前授权执行，Git 推送不授予平台权限。

最终在真实微信客户端检查：冷启动、核心流程、结算、重开、存档重进、声音、安全区、多指与前后台；安卓/iOS、不同账号和真实广告按本项目需要分别保留未验项。

本轮能够读取的是各仓库历史记录与官方类型声明引用，微信官方文档站的网页读取未成功；具体 API、限额和后台办理动作在执行任务时重新核对，不把本章当作当日后台规则清单。
