# TapTap 接入与发行

版本：2026-11-14.2。经验依据：E-TAP-01～09，见[经验条目](../EXPERIENCE_REGISTER.md)。

## 先确定目标形态与应用能力

按[TapTap 官方接入分流](https://developer.taptap.cn/agents/)确认平台托管 H5、Tap 小游戏、APK/PC 或制造版本。Cocos 的 Web Mobile 预览不自动等于目标应用接受 H5，也不能用 H5 ZIP 代替小游戏包。旧应用实际提供哪些入口，以该应用后台为准。

记录开发者、目标游戏、应用身份、当前上传入口和授权范围。新建应用、复用旧应用、绑定正式主包是不同动作；不能因另一个项目上传成功就借用其 AppID、广告位或账号权限。

## 构建和上传前检查

按项目既有原表与工具生成内容，核对源码提交、是否含未提交改动、配置清单、资源、版本显示和最终产物。正式包不包含 GM、测试夹具或另一平台的身份。

H5 使用真实静态生产构建，资源相对路径可在目标部署位置加载。源码 index.html、需要 TS 编译的入口、离线单文件版分别说明用途。ZIP 是否平铺或含外层目录，按实际上传入口核对，不能把某次后台的目录要求当成所有 API 的统一规定。

Tap 小游戏按当前官方引擎适配与转换路线生成。可复现地锁定工具版本、官方来源与摘要，核对 game.js、game.json、分包和实际平台脚本。不能人工加一个入口文件就宣称已经完成转换。

Cocos 成功码与日志、入口文件、实际资源同时检查。平台解析成功、创建开发版本、开发包列表可见、自测码可生成与手机可玩分别记录。官方工具下载与调用可以封装为项目脚本，不能为绕过平台限制修改其行为或伪造回执。

## 上传任务、解析与版本身份

保留同一上传任务、幂等标识和返回记录；中断或超时先查询结果再重试，不重复创建大量上传。服务端产物 ID、包体 ID、H5 版本 ID、应用版本与商店草稿绑定项分别登记。

上传成功后仍需核对解析状态、包体列表、目标开发版本和关联关系。某些路径只生成解析产物，需要后续创建开发版本；不能把尚未创建或绑定的产物说成已经可扫码。

后台旧标签页刷新后要等待真实结果，避免读取旧 DOM。只根据本次响应报告状态，不从过时页面、历史包号或本地缓存倒推当前结果。

## 自测与正式入口

在正确的目标包上验证冷启动、开始、核心过程、结束、重开、存档恢复、前后台、音频与安全区。源包改动后重新生成或确认该包对应的自测入口，不能交付旧试玩链接。

平台明确返回自测封禁、权限或前置条件错误时，记录错误与具体未完成阶段，按官方渠道处理。不能换账号、接口或包号规避限制，也不能把构建和上传通过写成手机可玩。

H5 与小游戏使用各自真实宿主能力验证，桌面预览与模拟广告只是对应范围的证据。开发二维码与正式玩家入口分别核对。

## 商店资料和内容审查

图标、宣传图、截图、录屏、简介和当前包一致。截图各自表达实际特色，录屏开头直接进入玩法，比例、短边、封面、时长和转码结果按当前入口检查。少宣传套话，不编个人开发经历、获奖或收益。

动态文本项目保留模板、词库、分支、运行样例和内容审计口径；不能只替换几条截图中的文本就称全内容已整改。有限样本不等于穷举全部动态组合。

退审意见、内容复核工单、版本审核、资料审核、备案、适龄与 AI 声明各自记录，不把某一项通过推成全部可以上线。若平台未指出具体内容，明确整改范围与仍待平台确认的部分，不自行扩大为所有历史题材永久禁止。

用户已经确认资料或当前包时避免重复提交；发现资料与包不一致，先核对可编辑草稿和目标版本，再按授权修正一次。不能为排查反复撤审或创建同名应用。

## 广告、云存档与榜单

按目标形态的当前接口接入；客户端只放允许公开的项目标识，服务端秘密与财务身份不进入客户端或共享材料。未开通广告时保持对应入口和奖励状态真实。

激励广告检查完成、取消、错误、无库存、暂停恢复、重复和迟到回调、奖励持久化以及关闭广告后的欠奖恢复。云存档检查账号、命名空间、版本冲突和回读，不能把本机保存当作跨账号云同步。

先验证免费流程完整，再按同条件对照核对可选广告是否有价值。播放、奖励兑现和收益分别记，不能用图表坐标或余额推算当天收入。广告开通、协议、备案及收款设置按当日后台分别核对。

## 提审与上线确认

提交前核对正确主包、双端或目标端游玩设置、方向、当前必填材料、隐私和已授权协议。审核通过后的生效方式与“提供游玩”设置都要检查，不能互相替代。

分别记录上传、解析、自测、绑定、提审、审核结果、发布生效和普通玩家正式入口。用普通账号从正式详情页进入正确版本并完成核心流程后，才能报告该入口在该设备可玩。

平台 CLI、后台 schema 和规则会变化。本章的历史经验用于防漏，具体命令、限额和操作应读取目标形态的当前官方文档，不复制旧版命令或另一项目的操作授权。
