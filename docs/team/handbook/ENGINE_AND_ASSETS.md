# 工程 资源与可靠性

版本：2026-11-12.2。经验依据：E-ENG-01～09，见[经验条目](../EXPERIENCE_REGISTER.md)。

## 保持明确的正式源码与技术路线

每个游戏说明正式源码、生成物、历史对照、引擎版本、目标平台和最终产物。Cocos 预览在浏览器中运行仍是引擎输出；H5 页面存在也不表示它继续作为正式客户端。

迁移时保留原玩法、配置、随机、存档和资源来源，再逐项证明新引擎的输入、显示与目标产物正确。用户已经停止旧端维护时，不继续双向同步或用旧 H5 覆盖原生源码。自动生成核心不重复当作独立原创模块统计。

先用小段真实目标流程验证资源导入、生命周期、遮罩、文字、滚动、输入和保存，再扩大窗口与内容。两个通用节点模板不能代表全部业务窗口已经可编辑；需要编辑器维护的界面应有对应场景或预制体。

## 原表 导出与来源

新增可调规则、内容、文案、属性、解锁、资源引用和项目要求的 UI 参数进入现有原表。按 ID 分段插入，保持紧凑，不新增无意义空行。修改后使用该项目原有工具导出，校验字段、引用、条件和实际入包数据。

不得直接编辑客户端 CSV 或 manifest 来绕过导表。一次性建表和版本迁移脚本不是日常编辑入口，不重复执行它们覆盖设计师后续修改。算法、协议、固定几何与可调规则的界限按项目文档说明。

原表采用候选文件时，先完成写入、关闭写句柄和候选校验，再在同一文件系统原子替换正式文件。不要以正在被校验进程读取的正式XLSX为目标执行逐字节覆盖；ZIP型文件可能被读到半写状态并报CRC或损坏。Windows共享锁导致替换或读取失败时，保留原文件，关闭占用或有界重试，不能退回非原子覆盖。测试和构建期间固定同一输入快照；确需改表则先停止相关验证，改完重新导表并按最终摘要重跑受影响检查。原子替换单文件不能代替多文件导出的批次一致性核对。


构建前验证原表、导出器、配置与资源摘要，陈旧导出应明确失败。CSV 覆盖引号、逗号、换行、BOM、尾部空列与各字段解析；不能把奖励数组分隔符与独立条件分隔符混为一谈。

配置说明、日志与分析放任务或 docs 目录，不污染原表和实际配置输出目录。客户端与服务端只生成项目实际采用的目标，不为单机游戏新增无用途的服务端表。

## 可替换的资源体系

沿用用户各游戏已经确认的 PNG、SpriteFrame、九宫、Label、字体和资源表规范。源图、派生物、.meta、来源与许可证分别留档；移动保留 UUID，替图核对锚点、非透明轮廓、视觉中心、拉伸保护和文字安全区。

运行时几何与资源绘制是否允许，以目标项目约定为准。不能把一个游戏的“禁止 Graphics”或字体尺寸无条件覆盖所有工程，也不能用占位图、静音或程序合成音冒充已要求的正式生成资源。

动画检查朝向、尺度、脚部锚点、镜像与动作切换，不能把相反方向姿势直接当连续走路帧。音频保留原始来源、剪辑、循环、音量与编码记录，逐平台验证实际加载和暂停恢复。

图集、压缩、字体子集、资源池等优化需比较实际产物与目标设备。没有测量就不宣称 Draw Call、内存、FPS 或启动已经改善。

## 编译产物而非仅源代码

Cocos 项目曾出现生命周期方法同名导致误调用、资源序列化字段丢失、赋图后遮罩尺寸改变，以及 Map/Set 迭代器被 loose spread 转译错误。保持纯规则与组件生命周期分工，采用目标版本支持的写法，并在真实构建中检查字段、资源和行为。

Node 测试通过不能替代实际 Creator 产物。成功退出码同时核对成功日志、入口文件、资源清单和运行版本；旧引擎诊断与此次失败分别记录。

修改布局或池化节点时完整恢复位置、比例、透明度、文字、事件与引用。高频创建 Label、每帧重排和不淘汰缓存需要先测量，再做有界复用；表现优化不合并真实数值事件或消耗模拟随机流。

## 保存 奖励与事务

资源、库存、钱包、任务与奖励按业务需要一起提交。确认交易时重算资格与报价签名，拒绝库存或条件已变的旧报价；重复点击不能重复成交。保存失败恢复事务前状态与共享引用，不能用会改变解锁的迁移读档代替回滚。

奖励请求绑定会话、局、选项版本和唯一凭据，完成凭据与奖励消费按协议持久化。测试旧回调、重开、关闭广告、更新版本与未兑现对象消失，避免看完视频后奖励失去用途。

多标签或旧实例不能覆盖较新进度。写入成功提示要有实际持久化依据；目标宿主回读、强制退出与恢复分别验证。客户端无法获得完成依据的中断场景，不承诺必定补发。

长档保存完整人物、年度、比赛、备份和结果；无损压缩、字典或增量协议须证明展开内容、旧版读取、配额和故障恢复，不通过删历史、减少备份或放宽限制掩盖问题。

## 连续流程与性能

从实际初始状态跑到后果显现：升级解锁、合同跨周、年终交接、关卡进度和恢复。边界夹具只证明边界，短时压力只证明对应压力；加速规则控制与自然对局分开记录。

比较同输入、同种子、同策略和相同硬件条件，说明测量包含 CPU、编码、I/O、网络或界面等待的哪部分。均值、峰值、异常样本与限制同时保留。静止或失败页 FPS 不能证明战斗帧率，软件渲染不能代替手机性能。

真实输入覆盖拖动、移出松手、pointercancel、多指、横竖屏和焦点变化。输入监听随组件释放，视口变化只改显示，不能重建战局或取消玩家已经完成的选择。
