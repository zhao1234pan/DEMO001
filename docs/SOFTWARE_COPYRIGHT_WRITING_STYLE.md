## 后续写法

- 先按玩家使用顺序介绍功能：在哪里、点击什么、发生什么、有哪些必要限制。优先用完整、自然的句子，不把正文压缩成检查项目。
- 功能介绍可以用“游戏”“玩家”“点击”“选择”“完成后”等常用词。软件全称、登记版本、界面按钮和角色名称按正式材料或冻结界面保留，不机械替换。
- 将“正常操作”“实际取图”“自然产生”“合法选择”“有效回调”等核验或实现用语放入制作记录；玩家说明只保留看懂功能所需的条件。例如“没有收到平台的观看完成结果时，不发放奖励”。
- 图注直接说明画面内容，例如“店员选择菜单”“第1关胜利结算”，不反复强调图片来自真实游玩。截图来源、逐图摘要和录屏仍完整保存在复核记录。
- 遵循用户的语气、句式和解释习惯，不照搬笔误、重复词或已被源码和实屏证实有误的旧描述。
- 自然措辞不能以删减内容换取：全部角色、地图、系统、完整流程、关键数值和广告使用条件均需保留。游戏内原有角色故事与技能说明按冻结配置保留，不作为文案润色对象。
