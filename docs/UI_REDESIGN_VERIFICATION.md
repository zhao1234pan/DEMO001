## 本轮修复的问题

- 启动Prefab不再序列化对美术分包的运行依赖；美术包首次加载失败也能显示原表导出的重试文字。
- 配置、PNG加载失败保留启动页；空图片/空错误回调也判为失败，归还同批成功加载的资源；重复点击不并发启动；销毁后不再创建游戏，统一归还加载引用。
- 九宫源图按原表尺寸缩小并同步边距，修正拉伸后边框挤压；遮罩保留半透明PNG，不误替换成面板。
- 移除重复旧HUD文字；GM在首页移到右上、其他界面保持原位置，避免遮挡操作；正式包禁用。
- 固定比例图标按Prefab框等比容纳，重复换图不会累积缩小；首页长屏背景等比覆盖。
- 设置缩为音乐/音效与版本；商品详情隐藏空统计，角色/首领信息紧凑排版；图鉴末行居中。
- 关卡缩略图使用新地面PNG，区分道路与背景；启动性能统计不遮挡UI。
