# 便利店金币长期用途

## 用户已确认（2026-10-17）

- 经营成长＋解锁店员或科技的选择范围。
- 已有用途为雇佣、设备改进、商品研发和制服；具体向战斗解锁的连接仍待设计实施。
- 此次确认是长期方向，尚未确定价格、分阶段门槛、可解锁清单、科技池归属及已解锁进度迁移；不能把未实现的连接表述为已上线。

## 接续设计依据

- 金币可扩展可选店员／科技内容，具体解锁列表、费用和条件先原始XLSX，再CSV及校验。

- 待挑战节奏与三商品位经营循环验收后，再确定解锁成本与获得节奏，避免先定费用再倒推玩法。
