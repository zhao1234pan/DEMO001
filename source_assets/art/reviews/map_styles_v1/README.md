本目录为Cocos Creator 3.8.8 Web Mobile真实画布导出，不是AI整屏效果图。方案、生成素材来源和复现方式见 [地图材质评审](../../../../docs/MAP_STYLE_REVIEW.md)。

- B：courtyard，便利店庭院。

- `level_03_*_battle.png`：第3关高密度复核，同样的确定性布阵规则。

每图JSON保存尺寸、引擎、皮肤、关卡、定格说明、导出时间与SHA256；并排图另记录三张输入图的哈希。中局示例8名店员、8个障碍、6空位、6敌人，用于一致性比较，不是自然游玩通关截图，不证明数值合理或手机性能。

截图从引擎帧尾直接保存，正式UI未另外拼接。只有灌木小模块使用内置imagegen生成，地图结构/渲染由Cocos代码实现。本目录在assets之外，不进入运行Bundle。
